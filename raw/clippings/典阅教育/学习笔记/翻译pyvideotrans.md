# 翻译pyvideotrans

[https://github.com/jianchang512/pyvideotrans/blob/main/docs/README_CN.md](https://github.com/jianchang512/pyvideotrans/blob/main/docs/README_CN.md)由于依赖包较大，你可以手动继续安装：

1. 在 CMD 或 PowerShell 中继续安装：  
cd D:\BaiduNetdiskDownload\pyvideotrans  
uv sync
2. 使用国内镜像加速（推荐）：  
cd D:\BaiduNetdiskDownload\pyvideotrans  
uv sync --index-url [https://mirrors.aliyun.com/pypi/simple/](https://mirrors.aliyun.com/pypi/simple/)
3. 安装完成后启动程序：

# 启动 GUI 界面
uv run sp.py

# 或使用命令行模式
uv run cli.py --help

🔧 手动运行（无需等待全部依赖）  
如果你只想快速验证环境，可以：

# 进入虚拟环境
.venv\Scripts\activate

# 检查 Python 版本
python --version

# 手动安装核心依赖（跳过大型包）
pip install PySide6
