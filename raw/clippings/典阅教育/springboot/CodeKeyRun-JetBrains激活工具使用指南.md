# CodeKey Run - JetBrains 激活工具使用指南

![1763535436263-6e36e17d-8373-4ad0-9b20-7f164a9d1e48.jpeg](./img/GspJV43kuSXfFe5g/1763535436263-6e36e17d-8373-4ad0-9b20-7f164a9d1e48-273851.jpeg)

### <font style="color:rgb(34, 34, 34);">CodeKey Run - JetBrains 激活工具使用指南</font>

工具简介\
CodeKey Run 是一个跨平台的 JetBrains IDE 激活工具，支持 Windows、Linux 和 macOS 系统，可自动激活 JetBrains 系列软件（如 IntelliJ IDEA、PyCharm、WebStorm 等）。

### <font style="color:rgb(34, 34, 34);">激活码网址</font>

[<font style="color:rgb(102, 102, 102);">https://ckey.run/</font>](https://ckey.run/)

### <font style="color:rgb(34, 34, 34);">1.Windows 系统使用方法</font>

激活步骤\
1.按下 Win + S 键，选择 Windows PowerShell (管理员)

![1763535436278-2bc7804c-00da-4081-9845-f5c7dc1e15e7.jpeg](./img/GspJV43kuSXfFe5g/1763535436278-2bc7804c-00da-4081-9845-f5c7dc1e15e7-122325.jpeg)

2.复制以下命令到 PowerShell 中执行：

<code><font style="color:rgb(199, 37, 78);background-color:rgb(245, 245, 245);">irm ckey.run | iex</font></code>

工具会自动扫描并激活所有已安装的 JetBrains 软件

等待片刻即可完成激活，无需手动输入激活码

### <font style="color:rgb(34, 34, 34);">2.Linux 系统使用方法</font>

1.激活步骤\ <code><font style="color:rgb(199, 37, 78);background-color:rgb(245, 245, 245);">wget --no-check-certificate ckey.run -O ckey.run && bash ckey.run</font></code>

### <font style="color:rgb(34, 34, 34);">3.macOS 系统使用方法</font>

<code><font style="color:rgb(199, 37, 78);background-color:rgb(245, 245, 245);">curl -L -o ckey.run ckey.run && bash ckey.run</font></code>

### <font style="color:rgb(34, 34, 34);">注意事项</font>

建议直接复制命令，避免手动输入错误

激活过程需要网络连接

工具会自动识别系统已安装的 JetBrains 产品

### <font style="color:rgb(34, 34, 34);">macOS 特殊说明</font>

1.macOS 默认未安装 wget，建议使用 curl 命令\
2.如果之前使用过其他激活工具导致激活失败，需要彻底清理：\
3.删除 JetBrains 相关应用的缓存文件

### <font style="color:rgb(34, 34, 34);">自定义激活</font>

1.如需自定义激活信息，请访问：ckey.run\
2.验证激活,激活成功后，打开任意 JetBrains IDE\
3.点击菜单栏 Help → Register
