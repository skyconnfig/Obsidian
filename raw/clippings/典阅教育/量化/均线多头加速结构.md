# 均线多头加速结构

你这张图其实描述的是一个经典的 **均线多头加速结构**，很多A股交易者把它叫 **“加托”结构**。核心逻辑是三条均线的多头递进：

+ **A点**：5日均线上穿10日均线（短线资金开始抢筹）
+ **B点**：5日均线上冲20日均线（市场情绪强化）
+ **C点**：10日均线上穿20日均线（中短周期资金形成合力）

最终三条均线形成一个 **封闭三角结构（多头托举）**。

口诀逻辑：

```plain
有效加托形成 → 买入
5日线下穿10日线 → 卖出
```

下面我给你一套 **可以直接回测的A股量化策略**（Python + DuckDB + pandas），也适合你现在做的 **本地量化研究框架**。

# 一、策略逻辑（量化版）
### 均线定义
```plain
MA5  = close.rolling(5).mean()
MA10 = close.rolling(10).mean()
MA20 = close.rolling(20).mean()
```

### 买入条件（加托形成）
满足：

```plain
1. MA5 上穿 MA10
2. MA5 上穿 MA20
3. MA10 上穿 MA20
```

并且要求顺序：

```plain
A: MA5 > MA10 且 前一天 MA5 <= MA10
B: MA5 > MA20
C: MA10 > MA20 且 前一天 MA10 <= MA20
```

最终结构：

```plain
MA5 > MA10 > MA20
```

成交量确认：

```plain
Volume > 5日均量
```

---

### 卖出条件
```plain
MA5 下穿 MA10
```

或者

```plain
止损：-5%
```

# 二、完整 Python 回测代码
假设你的数据在 DuckDB：

表结构：

```plain
stock_daily
--------------
ts_code
trade_date
open
high
low
close
volume
```

代码：

```python
import duckdb
import pandas as pd

con = duckdb.connect("stock.db")

df = con.execute("""
SELECT *
FROM stock_daily
WHERE ts_code='000001.SZ'
ORDER BY trade_date
""").df()

# ===== 计算均线 =====

df["ma5"] = df["close"].rolling(5).mean()
df["ma10"] = df["close"].rolling(10).mean()
df["ma20"] = df["close"].rolling(20).mean()

df["vol5"] = df["volume"].rolling(5).mean()

# ===== 信号 =====

df["buy_signal"] = (
    (df["ma5"] > df["ma10"]) &
    (df["ma5"].shift(1) <= df["ma10"].shift(1)) &
    (df["ma10"] > df["ma20"]) &
    (df["ma10"].shift(1) <= df["ma20"].shift(1)) &
    (df["volume"] > df["vol5"])
)

df["sell_signal"] = (
    (df["ma5"] < df["ma10"]) &
    (df["ma5"].shift(1) >= df["ma10"].shift(1))
)

# ===== 回测 =====

position = 0
buy_price = 0
capital = 100000
shares = 0

equity_curve = []

for i,row in df.iterrows():

    if position == 0 and row["buy_signal"]:

        buy_price = row["close"]
        shares = capital // buy_price
        capital -= shares * buy_price
        position = 1

    elif position == 1:

        # 止损
        if row["close"] < buy_price * 0.95:
            capital += shares * row["close"]
            shares = 0
            position = 0

        elif row["sell_signal"]:
            capital += shares * row["close"]
            shares = 0
            position = 0

    equity = capital + shares * row["close"]
    equity_curve.append(equity)

df["equity"] = equity_curve

print("最终资金:", df["equity"].iloc[-1])
```

# 三、全市场选股扫描（核心）
你真正要用的是 **每天扫描全A股**：

```sql
SELECT
ts_code,
trade_date,
close,
AVG(close) OVER w5  AS ma5,
AVG(close) OVER w10 AS ma10,
AVG(close) OVER w20 AS ma20
FROM stock_daily
WINDOW
w5  AS (PARTITION BY ts_code ORDER BY trade_date ROWS 4 PRECEDING),
w10 AS (PARTITION BY ts_code ORDER BY trade_date ROWS 9 PRECEDING),
w20 AS (PARTITION BY ts_code ORDER BY trade_date ROWS 19 PRECEDING)
```

筛选：

```plain
ma5 > ma10
ma10 > ma20
ma5昨天 <= ma10昨天
ma10昨天 <= ma20昨天
```

得到 **今日加托股票池**。
