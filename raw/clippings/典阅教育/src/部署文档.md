# 部署文档

根据我对项目的分析，这是一个包含三个后端微服务和两个前端应用的完整系统。以下是详细的启动步骤：                 

                                                                                                                   系统架构概览                                                                                                   

                                                                                                                 

  - 后端服务：                                                                                                   

    - system-api (端口 8887) - 系统管理服务                                                                    

    - question-api (端口 8886) - 题库考试服务

    - teller-api (端口 8890) - 柜员门户服务

  - 前端应用：

    - admin-web (管理员界面) - 端口 5173

    - teller-web (柜员界面) - 端口 5174

  - 依赖服务：

    - MySQL 8.0 数据库

    - Redis 5.0+ 缓存服务



  启动前准备



  1. 确保依赖服务已启动



  首先启动数据库和缓存服务：



  # 启动 MySQL 服务 (通常通过服务管理器或命令)

  # Windows: net start mysql80 或通过 MySQL Workbench 启动

  # Linux: sudo systemctl start mysql



  # 启动 Redis 服务

  # Windows: redis-server.exe

  # Linux: sudo systemctl start redis



  2. 初始化数据库



  # 导入数据库结构 (如果尚未导入)

  mysql -u root -p < db/xabank20250920.sql



  服务启动顺序



  第一步：启动后端服务



  按以下顺序启动后端服务（确保JDK 21已安装）：



  1. 启动 system-api (系统管理服务)



  cd D:\dyjy\xayh\lastservices\rebuild-src\backend\system-api

  mvn spring-boot:run -Dspring-boot.run.profiles=dev



  2. 启动 question-api (题库考试服务)



  在新终端窗口中执行：



  cd D:\dyjy\xayh\lastservices\rebuild-src\backend\question-api

  mvn spring-boot:run -Dspring-boot.run.profiles=dev



  3. 启动 teller-api (柜员门户服务)



  在新终端窗口中执行：



  cd D:\dyjy\xayh\lastservices\rebuild-src\backend\teller-api

  mvn spring-boot:run -Dspring-boot.run.profiles=dev



  第二步：启动前端服务



  1. 启动管理员前端



  在新终端窗口中执行：



  cd D:\dyjy\xayh\lastservices\rebuild-src\frontend\admin-web

  npm install

  npm run dev



  2. 启动柜员前端



  在新终端窗口中执行：



  cd D:\dyjy\xayh\lastservices\rebuild-src\frontend\teller-web

  npm install

  npm run dev

  - 前端API代理已配置为对应后端服务端口



  常见问题排查



  1. 端口冲突: 如果端口被占用，请检查并关闭相关进程，或修改配置文件中的端口号

  2. 数据库连接失败: 确认MySQL服务正在运行，并检查用户名和密码是否正确

  3. Redis连接失败: 确认Redis服务正在运行

  4. 编译错误: 如果后端服务启动失败，请确保您已经完成了Java 21迁移工作



  系统验证



  要验证系统是否正常工作：



  1. 检查所有后端服务是否成功启动并在各自端口上运行

  2. 打开浏览器访问API文档页面，确认可以访问

  3. 启动前端应用，确保能够加载页面

  4. 尝试进行简单的API调用以确认后端功能正常
