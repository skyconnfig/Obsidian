  如何使用 GSD



  1. 开始新项目



  在 Claude Code 中运行：



  /gsd:new-project



  这会引导你完成：

  - 回答问题描述你的项目想法

  - 系统会自动研究领域知识

  - 提取需求（v1, v2, 范围外）

  - 创建路线图



  2. 核心工作流



  GSD 采用 讨论 → 计划 → 执行 → 验证 的循环：



  /gsd:discuss-phase 1    # 讨论阶段1的实现细节

  /gsd:plan-phase 1       # 研究并计划

  /gsd:execute-phase 1    # 执行所有计划任务

  /gsd:verify-work 1      # 验证工作是否正常

  /gsd:ship 1            # 创建PR（可选）



  3. 快速模式（临时任务）



  对于不需要完整流程的小任务：



  /gsd:quick



  或者带研究：



  /gsd:quick --research



  4. 自动下一步



  /gsd:next



  自动检测并执行下一步该做什么。



  5. 常用命令



  ┌─────────────────────────┬────────────────────────────────┐

  │          命令           │              用途              │

  ├─────────────────────────┼────────────────────────────────┤

  │ /gsd:progress           │ 查看当前进度                   │

  ├─────────────────────────┼────────────────────────────────┤

  │ /gsd:help               │ 显示所有命令                   │

  ├─────────────────────────┼────────────────────────────────┤

  │ /gsd:settings           │ 配置模型和代理                 │

  ├─────────────────────────┼────────────────────────────────┤

  │ /gsd:set-profile budget │ 切换到经济模式（Sonnet+Haiku） │

  ├─────────────────────────┼────────────────────────────────┤

  │ /gsd:update             │ 更新 GSD                       │

  └─────────────────────────┴────────────────────────────────┘



  6. 配置文件



  项目设置保存在 .planning/config.json，可以调整：

  - mode: interactive（交互）或 yolo（自动批准）

  - granularity: coarse/standard/fine（阶段粒度）

  - git.branching_strategy: 分支策略



  7. 提示



  - 使用 --chain 自动链接步骤：/gsd:discuss-phase 1 --chain

  - 使用 --batch 批量回答问题加速讨论

  - 运行 Claude Code 时建议加上 --dangerously-skip-permissions 避免频繁批准

  - 每个任务都会创建独立的 git commit



  现在你可以打开一个空目录（或现有项目）并运行 /gsd:new-project 开始使用！
