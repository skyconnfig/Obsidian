# 产品需求文档

## **产品需求文档（PRD）**
#### 技术选型：前端用 Vue.js   UI组件库   ElementPlus UI（Vue）  
#### 数据库选型：Mysql
#### 后端开发： Spring Boot  
### 1. 用户登录功能
+ **功能描述**：用户可选择不同角色（管理员、老师、裁判员、学生代表）进行登录。登录页面提供“记住密码”和“注册”功能。
+ **需求**：
    - 用户输入用户名、密码。
    - 角色选择（管理员、老师、裁判员、学生代表）字段。
    - “记住密码”功能。
    - 点击“注册”跳转到注册页面。

---

### 2. 系统管理（管理员端）
+ **功能描述**：管理员可以管理系统中的用户、班级、学生数据等。
+ **需求**：
    - 用户网点管理：新增、修改、删除、查询。
    - 培训班级管理：新增、修改、删除、查询、网点查询。
    - 学生管理：新增、修改、删除、批量管理、导入/导出Excel。
    - 密码修改功能。

---

### 3. 练习手工卷管理
+ **功能描述**：管理员可以设置练习手工卷并进行管理。
+ **需求**：
    - 新增、修改、删除、批量操作。
    - 时间加分设置，每提前一秒加0.01分。
    - 设置币种面值和数量，自动计算总值。
    - 激活/关闭激活功能。
    - 学生端：点击手工点钞图标跳转到考试界面。

---

### 4. 翻打传票管理
+ **功能描述**：管理员设置传票考试内容并管理考试。
+ **需求**：
    - 传票类型设置（内置类型：A、B、C、D、E、F、G、H、I、J）。
    - 传票内容设置，包括页码、起始页码等。
    - 导入/导出Excel功能。
    - 激活/关闭激活功能。
    - 学生端：点击传票图标跳转到考试界面。

---

### 5. 字符录入管理
+ **功能描述**：管理员可以设置字符录入任务，并管理字符录入任务。
+ **需求**：
    - 字符录入个数设置，支持导入txt文件。
    - 时间加分设置。
    - 新增、删除、批量操作。
    - 激活/关闭激活功能。
    - 学生端：点击字符录入图标跳转到考试界面。

---

### 6. 考核任务管理
+ **功能描述**：管理员可以管理考核任务的设置、时间等。
+ **需求**：
    - 考核计划管理：新增、修改、删除、考题预览、生成考题。
    - 考核任务设置：新增、修改、删除、题目配置。
    - 考核时间设置：新增、修改、删除、激活、关闭激活。
    - 学生端：点击考核任务图标跳转到考试界面。

---

## **数据库结构设计**
### 1. 用户表（users）
| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | INT | 用户ID（主键） |
| username | VARCHAR(255) | 用户名 |
| password | VARCHAR(255) | 密码 |
| role | ENUM('admin', 'teacher', 'referee', 'student_representative') | 用户角色 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |


### 2. 学生表（students）
| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | INT | 学生ID（主键） |
| user_id | INT | 用户ID（外键） |
| student_id | VARCHAR(255) | 学生学号 |
| class_id | INT | 班级ID（外键） |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |


### 3. 班级表（classes）
| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | INT | 班级ID（主键） |
| name | VARCHAR(255) | 班级名称 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |


### 4. 手工卷设置表（manual_exams）
| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | INT | 手工卷ID（主键） |
| exam_name | VARCHAR(255) | 卷子名称 |
| time_bonus | DECIMAL(5,2) | 时间奖励分数 |
| currency_type | ENUM('CNY', 'USD') | 币种类型 |
| total_amount | INT | 总金额 |
| is_active | BOOLEAN | 是否激活 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |


### 5. 传票设置表（voucher_exams）
| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | INT | 传票ID（主键） |
| exam_name | VARCHAR(255) | 传票名称 |
| page_start | INT | 起始页码 |
| page_end | INT | 结束页码 |
| voucher_type | ENUM('A', 'B', 'C', 'D', 'E', 'F', 'G', 'H', 'I', 'J') | 传票类型 |
| is_active | BOOLEAN | 是否激活 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |


### 6. 考核任务表（assessment_tasks）
| 字段名 | 类型 | 说明 |
| --- | --- | --- |
| id | INT | 考核任务ID（主键） |
| task_name | VARCHAR(255) | 任务名称 |
| task_type | ENUM('manual', 'voucher', 'character') | 任务类型 |
| is_active | BOOLEAN | 是否激活 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

## **UI布局规划**
### 1. **登录页**：
+ **顶部**：logo、系统名称。
+ **主区域**：
    - 用户名、密码输入框。
    - 角色选择框（管理员、老师、裁判员、学生代表）。
    - 记住密码、注册按钮。
    - 登录按钮。

### 2. **管理员主页**：
+ **顶部导航栏**：包含系统名称、用户信息、退出登录。
+ **左侧菜单**：系统管理、练习手工卷管理、翻打传票管理、字符录入管理、考核任务管理。
+ **主区域**：显示当前模块的管理功能，如新增、修改、删除按钮等。

### 3. **学生端主页**：
+ **顶部导航栏**：包含系统名称、用户名、当前模块。
+ **主区域**：显示学生可以选择的6个模块（如手工卷、传票、字符录入、考核任务等），点击进入。
