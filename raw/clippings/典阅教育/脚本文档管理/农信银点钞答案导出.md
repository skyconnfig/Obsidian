# 农信银点钞答案导出

```sql
----------手工点钞-----------------
select a.CountingName 试卷 ,b.DataDic_Value 面额 ,b.CountNum 张数,b.CountValue 金额 from dbo.dal_Counting as a 
inner join dbo.dal_Counting_Detail as b on a.Id=b.CountingId 
order by CountingId,b.DataDic_Value desc

----------机器点钞------------------
select a.BanknoteName 试卷 ,b.MachineBillChar 答案 from dbo.dal_MachineBill as a
inner join dbo.dal_MachineBill_Detail as b on a.Id=b.MachineBillId
order by a.Id desc,b.Id 
```
