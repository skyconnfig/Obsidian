<font style="color:rgb(0, 0, 0);">出现这个错误是因为 IIS 7 采用了更安全的 web.config 管理机制，默认情况下会锁住配置项不允许更改。要取消锁定可以运行命令行</font>

<font style="color:rgb(0, 0, 0);">%windir%\system32\inetsrv\appcmd unlock config -section:system.webServer/handlers [就是这一行，帮我搞定！]。</font>

<font style="color:rgb(0, 0, 0);">其中的 handlers是错误信息中红字显示的节点名称。</font>

<font style="color:rgb(0, 0, 0);">如果modules也被锁定，可以运行%windir%\system32\inetsrv\appcmd unlock config -section:system.webServer/modules</font>

<font style="color:rgb(0, 0, 0);">另外，如果使用Asp.net的朋友，在安装IIS7的时候一定记得勾选Asp.net，默认不选，也会出现类似的错误信息</font>
