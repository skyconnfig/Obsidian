# 应用 IIS 配置选项来提高 IIS 性能

## <font style="color:#000000;background-color:#E7E9E8;"></font>
<font style="color:#000000;background-color:#E7E9E8;">Internet 信息服务 (IIS) 公开了许多影响 IIS 性能的配置参数。本主题介绍其中几个参数，并提供有关设置参数值以提高 IIS 性能的一般指导。</font>

### <font style="color:#000000;background-color:#E7E9E8;">仅记录必要信息或完全禁用 IIS 日志记录</font>
<font style="color:#000000;background-color:#E7E9E8;">在生产环境中，应尽量减少甚至禁用 IIS 日志记录。要禁用日志记录，请按照以下步骤操作：</font>

1. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“开始”</font>**<font style="color:#000000;background-color:#E7E9E8;">，指向</font>**<font style="color:#000000;background-color:#E7E9E8;">“所有程序”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击“</font>**<font style="color:#000000;background-color:#E7E9E8;">管理工具”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“Internet 信息服务 (IIS) 管理器”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>
2. <font style="color:#000000;background-color:#E7E9E8;">在</font>**<font style="color:#000000;background-color:#E7E9E8;">“连接”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中，单击展开</font>**<font style="color:#000000;background-color:#E7E9E8;">“站点”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击选择要禁用日志记录的网站，单击选择</font>**<font style="color:#000000;background-color:#E7E9E8;">“功能视图”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后双击</font>**<font style="color:#000000;background-color:#E7E9E8;">“日志记录”</font>**<font style="color:#000000;background-color:#E7E9E8;">功能。</font>
3. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“操作”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中的</font>**<font style="color:#000000;background-color:#E7E9E8;">“禁用”</font>**<font style="color:#000000;background-color:#E7E9E8;">以禁用该网站的日志记录。</font>

1. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“开始”</font>**<font style="color:#000000;background-color:#E7E9E8;">，指向</font>**<font style="color:#000000;background-color:#E7E9E8;">“所有程序”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击“</font>**<font style="color:#000000;background-color:#E7E9E8;">管理工具”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“Internet 信息服务 (IIS) 管理器”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>

### <font style="color:#000000;background-color:#E7E9E8;">调整“每处理器的 ASP 线程数限制”属性的值</font>
<font style="color:#000000;background-color:#E7E9E8;">“ASP</font>**<font style="color:#000000;background-color:#E7E9E8;">每处理器线程数限制”</font>**<font style="color:#000000;background-color:#E7E9E8;">属性指定 IIS 创建的每个处理器的最大工作线程数。增加“每处理器线程数限制”的值，直到处理器利用率至少达到 50% 或更高。此设置可以显著影响 Web 应用程序的可伸缩性和服务器的总体性能。由于此属性定义可以同时执行的最大 ASP 请求数，因此除非 ASP 应用程序对外部组件进行扩展调用，否则此设置应保持为默认值。在这种情况下，您可以增加“每处理器线程数限制”的值。这样做允许服务器创建更多线程来处理更多并发请求。“每处理器线程数限制”的默认值为 25。此属性的最大建议值为 100。</font>

<font style="color:#000000;background-color:#E7E9E8;">要增加每个处理器的线程数限制值，请按照以下步骤操作：在</font>**<font style="color:#000000;background-color:#E7E9E8;">“连接”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中，选择 Web 服务器，单击以选择</font>**<font style="color:#000000;background-color:#E7E9E8;">“功能视图”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后双击</font>**<font style="color:#000000;background-color:#E7E9E8;">ASP</font>**<font style="color:#000000;background-color:#E7E9E8;">功能。</font>

1. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“开始”</font>**<font style="color:#000000;background-color:#E7E9E8;">，指向</font>**<font style="color:#000000;background-color:#E7E9E8;">“所有程序”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击“</font>**<font style="color:#000000;background-color:#E7E9E8;">管理工具”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“Internet 信息服务 (IIS) 管理器”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>
2. <font style="color:#000000;background-color:#E7E9E8;">在</font>**<font style="color:#000000;background-color:#E7E9E8;">“连接”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中，选择 Web 服务器，单击以选择</font>**<font style="color:#000000;background-color:#E7E9E8;">“功能视图”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后双击</font>**<font style="color:#000000;background-color:#E7E9E8;">“ASP</font>**<font style="color:#000000;background-color:#E7E9E8;">功能”。</font>
3. <font style="color:#000000;background-color:#E7E9E8;">单击展开</font>**<font style="color:#000000;background-color:#E7E9E8;">“行为”</font>**<font style="color:#000000;background-color:#E7E9E8;">下的</font>**<font style="color:#000000;background-color:#E7E9E8;">“限制属性”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“每个处理器的线程数限制” ，输入</font>****<font style="color:#000000;background-color:#E7E9E8;">每个处理器的线程数限制</font>**<font style="color:#000000;background-color:#E7E9E8;">的所需值</font><font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“操作”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中的</font>**<font style="color:#000000;background-color:#E7E9E8;">“应用”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>

### <font style="color:#000000;background-color:#E7E9E8;">调整 ASP 队列长度属性的值</font>
<font style="color:#000000;background-color:#E7E9E8;">调整此属性的目的是确保良好的响应时间，同时尽量减少 ASP 请求队列已满时服务器向客户端发送 HTTP 503（服务器太忙）错误的频率。如果 ASP 队列长度属性的值太低，服务器将以更高的频率发送 HTTP 503 错误。如果 ASP 队列长度属性的值太高，用户可能会认为服务器没有响应，而实际上他们的请求正在队列中等待。通过在高流量期间观察队列，您应该可以辨别出 Web 请求峰值和谷值的模式。记下峰值，并将 ASP 队列长度属性的值设置为略高于峰值的值。使用队列来处理短期峰值，确保响应时间，并在出现持续的意外峰值时限制系统以避免过载。如果您没有用于调整 ASP 队列长度属性的数据，那么一个好的起点是设置队列与总线程的一对一比率。例如，如果“每处理器的 ASP 线程数限制”属性设置为 25，且您有四个处理器（4 * 25 = 100 个线程），则将“ASP 队列长度”属性设置为 100，并从该位置开始进行调整。</font>

<font style="color:#000000;background-color:#E7E9E8;">要增加队列长度属性的值，请按照以下步骤操作：</font>

1. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“开始”</font>**<font style="color:#000000;background-color:#E7E9E8;">，指向</font>**<font style="color:#000000;background-color:#E7E9E8;">“所有程序”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击“</font>**<font style="color:#000000;background-color:#E7E9E8;">管理工具”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“Internet 信息服务 (IIS) 管理器”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>
2. <font style="color:#000000;background-color:#E7E9E8;">在</font>**<font style="color:#000000;background-color:#E7E9E8;">“连接”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中，选择 Web 服务器，单击以选择</font>**<font style="color:#000000;background-color:#E7E9E8;">“功能视图”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后双击</font>**<font style="color:#000000;background-color:#E7E9E8;">“ASP</font>**<font style="color:#000000;background-color:#E7E9E8;">功能”。</font>

### <font style="color:#000000;background-color:#E7E9E8;">调整 MaxPoolThreads 注册表项</font>
<font style="color:#000000;background-color:#E7E9E8;">此设置指定每个处理器要创建的池线程数。池线程监视网络中的请求并处理传入的请求。MaxPoolThreads 计数不包括 ISAPI 应用程序使用的线程。通常，每个处理器不应创建超过 20 个线程。MaxPoolThreads 是一个 REG_DWORD 注册表项，位于 HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\InetInfo\Parameters\，默认值为 4。</font>

### <font style="color:#000000;background-color:#E7E9E8;">为 IIS 7.5/7.0 集成模式配置 ASP.NET 2.0 MaxConcurrentRequests</font>
<font style="color:#000000;background-color:#E7E9E8;">当 ASP.NET 2.0 以集成模式托管在 IIS 7.5/7.0 上时，线程的使用处理方式与经典模式中的 IIS 7.5/7.0 不同。当 ASP.NET 2.0 以集成模式托管在 IIS 7.5 上时，ASP.NET 2.0 会限制并发执行请求的数量，而不是并发执行请求的线程数量。对于同步场景，这将间接限制线程数量，因为请求数量将与线程数量相同。但对于异步场景，请求数量和线程数量可能会有很大差异，因为请求数量可能远多于线程数量。当在集成模式下的 IIS 7.5 上运行 ASP.NET 2.0 时，machine.config 中“httpRuntime”元素的 minFreeThreads 和 minLocalRequestFreeThreads 将被忽略。对于 IIS 7.5 集成模式，HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\ASP.NET\2.0.50727.0 中的名为 MaxConcurrentRequestsPerCPU 的 DWORD 决定每个 CPU 的并发请求数。默认情况下，该注册表项不存在，每个 CPU 的请求数限制为 12。.NET Framework 3.5 SP1 包含对 v2.0 二进制文件的更新，支持通过 aspnet.config 文件配置 IIS 应用程序池。此配置仅适用于集成模式（经典/ISAPI 模式忽略这些设置）。下面列出了具有默认值的新 aspnet.config 配置部分：</font>

<font style="color:#000000;background-color:#E7E9E8;">复制</font>

```plain
<system.web>
   <applicationPool maxConcurrentRequestsPerCPU="12" maxConcurrentThreadsPerCPU="0" requestQueueLimit="5000"/>
</system.web>
```

<font style="color:#000000;background-color:#E7E9E8;">在 IIS 7.5 集成模式下，machine.config 文件的“processModel”部分中的 maxWorkerThreads 和 maxIoThreads 参数本身不用于控制正在运行的请求数，但它们仍用于控制 ASP.NET 使用的 CLR 线程池的大小。当 machine.config 的“processModel”部分具有“autoConfig=true”（这是默认设置）时，这将为应用程序池提供每个逻辑 CPU 最多 100 个工作线程 (MaxWorkerThreads)。因此，具有 2 个双核 CPU 的普通商用服务器将具有 400 个 MaxWorkerThreads。除了要求最苛刻的应用程序外，这应该足以满足所有应用程序的需求。</font>

<font style="color:#000000;background-color:#E7E9E8;">有关在 IIS 7.5 上配置 ASP.NET 线程使用的详细信息，请参阅</font>[<font style="color:#000000;background-color:#E7E9E8;">Thomas Marquardt 的有关 IIS 7.0 上的 ASP.NET 线程使用的博客</font>](https://learn.microsoft.com/en-us/archive/blogs/tmarq/)<font style="color:#000000;background-color:#E7E9E8;">（</font>[<font style="color:#000000;background-color:#E7E9E8;">https://go.microsoft.com/fwlink/?LinkId=157518</font>](https://go.microsoft.com/fwlink/?LinkId=157518)<font style="color:#000000;background-color:#E7E9E8;">）。</font>

### <font style="color:#000000;background-color:#E7E9E8;">为 IIS 7.5/7.0 集成模式配置 ASP.NET 4 MaxConcurrentRequests</font>
<font style="color:#000000;background-color:#E7E9E8;">在 .NET Framework 4 中，maxConcurrentRequestsPerCPU 的默认设置为 5000，这是一个非常大的数字，因此将允许大量异步请求同时执行。有关更多信息，请参阅</font>[<font style="color:#000000;background-color:#E7E9E8;"><applicationPool> 元素（Web 设置）</font>](https://learn.microsoft.com/en-us/dotnet/framework/configure-apps/file-schema/web/applicationpool-element-web-settings)<font style="color:#000000;background-color:#E7E9E8;"> </font><font style="color:#000000;background-color:#E7E9E8;">(</font><font style="color:#000000;background-color:#E7E9E8;"> </font>[<font style="color:#000000;background-color:#E7E9E8;">https://go.microsoft.com/fwlink/?LinkID=205339</font>](https://go.microsoft.com/fwlink/?LinkID=205339)<font style="color:#000000;background-color:#E7E9E8;"> </font><font style="color:#000000;background-color:#E7E9E8;">)。</font>

<font style="color:#000000;background-color:#E7E9E8;">对于 IIS 7.5/7.0 集成模式，HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\ASP.NET\4.0.30319.0 中的名为 MaxConcurrentRequestsPerCPU 的 DWORD 决定每个 CPU 的并发请求数。默认情况下，该注册表项不存在，每个 CPU 的请求数限制为 5000。</font>

### <font style="color:#000000;background-color:#E7E9E8;">启用 IIS HTTP 压缩</font>
<font style="color:#000000;background-color:#E7E9E8;">为了更有效地利用可用带宽，请启用 IIS HTTP 压缩。无论您的内容是从本地存储还是 UNC 资源提供的，HTTP 压缩都可以缩短启用压缩的浏览器和 IIS 之间的传输时间。</font>

+ **<font style="color:#000000;background-color:#E7E9E8;">要在 Web 服务器级别配置压缩：</font>**
    1. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“开始”</font>**<font style="color:#000000;background-color:#E7E9E8;">，指向</font>**<font style="color:#000000;background-color:#E7E9E8;">“所有程序”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击“</font>**<font style="color:#000000;background-color:#E7E9E8;">管理工具”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“Internet 信息服务 (IIS) 管理器”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>
    2. <font style="color:#000000;background-color:#E7E9E8;">在</font>**<font style="color:#000000;background-color:#E7E9E8;">“连接”</font>**<font style="color:#000000;background-color:#E7E9E8;">窗格中，选择 Web 服务器，单击以选择</font>**<font style="color:#000000;background-color:#E7E9E8;">“功能视图”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后双击</font>**<font style="color:#000000;background-color:#E7E9E8;">“压缩”</font>**<font style="color:#000000;background-color:#E7E9E8;">功能。</font>

+ **<font style="color:#000000;background-color:#E7E9E8;">要在网站级别配置压缩：</font>**
    1. <font style="color:#000000;background-color:#E7E9E8;">单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“开始”</font>**<font style="color:#000000;background-color:#E7E9E8;">，指向</font>**<font style="color:#000000;background-color:#E7E9E8;">“所有程序”</font>**<font style="color:#000000;background-color:#E7E9E8;">，单击“</font>**<font style="color:#000000;background-color:#E7E9E8;">管理工具”</font>**<font style="color:#000000;background-color:#E7E9E8;">，然后单击</font>**<font style="color:#000000;background-color:#E7E9E8;">“Internet 信息服务 (IIS) 管理器”</font>**<font style="color:#000000;background-color:#E7E9E8;">。</font>
