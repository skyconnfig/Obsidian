# 比赛常用

```sql
----大堂经理和综合柜台查询分数和提交时间-----
select a.LoginNo,b.Scores,b.UpdateTime from tb_User a inner join bsi_TotalResult b on b.AddUserId=a.U_ID
----客户经理和理财经理查询分数和提交时间-----
select a.Teller_No,b.Result,b.SubmitTime from bi_BankTeller a inner join zhyw_ExamResult b on b.TellerId=a.Id

----查询大堂经理某个学生的成绩记录-------
select * from bsi_TotalResult where  UserId='2658'
select * from tb_User  where LoginNo='s0103'

```
