# 农信银匹配对应的计划更新时间

### 更新零售对公
```bash
--查询
SELECT 
    T.Id AS TimerId, 
    T.ComplexPlanId, 
    T.BeginTime AS CurrentBeginTime, 
    P.Plan_Name
FROM dal_ComplexTimer T
INNER JOIN dal_ComplexPlan P ON T.ComplexPlanId = P.Id
WHERE P.Plan_Name LIKE '%对公综合练习题%' 
   OR P.Plan_Name LIKE '%零售综合练习题%';
   --更新
UPDATE T
SET T.BeginTime = '2026-03-20 09:01:00.000'
FROM dal_ComplexTimer T
INNER JOIN dal_ComplexPlan P ON T.ComplexPlanId = P.Id
WHERE P.Plan_Name LIKE '%对公综合练习题%' 
   OR P.Plan_Name LIKE '%零售综合练习题%';
```

### 更新传票
```bash
BEGIN TRAN;

UPDATE [dal_SummonCount]
SET BeginTime = '2026-03-24 09:01:00.000'
WHERE SummonCountName LIKE '传票练习%';

-- 先执行验证查询确认无误
SELECT * FROM [dal_SummonCount] WHERE SummonCountName LIKE '传票练习%';

-- 确认无误后提交
COMMIT TRAN;
-- 如有问题则回滚：ROLLBACK TRAN;
```
