# Windows Server 2012 R2如何设置密码长度最

# <font style="color:rgb(51, 51, 51);"></font>
1. <font style="color:rgb(51, 51, 51);">我的电脑→管理打开服务器管理器 ，如图②所示</font>![1653615884961-a6a8a607-a018-4d92-aed2-adf305d02fa1.png](./img/KGNpVXC6wFBkUaXb/1653615884961-a6a8a607-a018-4d92-aed2-adf305d02fa1-444427.png)![1653615884975-b0484db4-df79-4d40-86ce-102714221266.png](./img/KGNpVXC6wFBkUaXb/1653615884975-b0484db4-df79-4d40-86ce-102714221266-327418.png)
2. <font style="color:rgb(51, 51, 51);">点击服务器管理器工具栏→计算机管理，打开计算机管理工具</font>![1653615884989-d9b4fcd6-0f5e-4a95-92e3-481de8207acb.png](./img/KGNpVXC6wFBkUaXb/1653615884989-d9b4fcd6-0f5e-4a95-92e3-481de8207acb-728253.png)
3. <font style="color:rgb(51, 51, 51);">计算机管理工具中依次展开 计算机管理→本地用户和组→用户 如图所示</font>![1653615884969-38c81ea7-316b-4b60-aebc-b964104789bc.png](./img/KGNpVXC6wFBkUaXb/1653615884969-38c81ea7-316b-4b60-aebc-b964104789bc-817926.png)
4. <font style="color:rgb(51, 51, 51);">选中要修改密码的账户，右键→设置密码</font>![1653615884967-03cb4dbc-994f-4c91-a223-05b121e6d214.png](./img/KGNpVXC6wFBkUaXb/1653615884967-03cb4dbc-994f-4c91-a223-05b121e6d214-249329.png)
5. <font style="color:rgb(51, 51, 51);">弹出提示界面 ，直接点继续</font>![1653615885801-09c3d375-178e-403c-bf71-bd4c5755b268.png](./img/KGNpVXC6wFBkUaXb/1653615885801-09c3d375-178e-403c-bf71-bd4c5755b268-562966.png)
