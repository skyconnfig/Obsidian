# 客户经理删除多余案列

***

## ✅ 正确去重脚本（使用真实列名 `Id`）

### 🔍 第一步：预览将被删除的重复行（安全！）

```sql
WITH CTE AS (
    SELECT 
        Id,  -- ✅ 正确列名
        ContestId,
        BankSiteId,
        ComplexPlanId,
        ROW_NUMBER() OVER (
            PARTITION BY ContestId, BankSiteId, ComplexPlanId 
            ORDER BY Id ASC  -- 按 Id 升序，保留最早插入的记录
        ) AS rn
    FROM [stt_khjl].[dbo].[dal_ComplexTimer]
)
SELECT * 
FROM CTE 
WHERE rn > 1
ORDER BY ContestId, BankSiteId, ComplexPlanId, Id;
```

### 🗑 第二步：确认无误后执行删除

```sql
WITH CTE AS (
    SELECT 
        Id,
        ROW_NUMBER() OVER (
            PARTITION BY ContestId, BankSiteId, ComplexPlanId 
            ORDER BY Id ASC
        ) AS rn
    FROM [stt_khjl].[dbo].[dal_ComplexTimer]
)
DELETE FROM CTE 
WHERE rn > 1;
```

***

## 📌 说明

| 您之前认为的列名 | 实际列名 | 类型 |
| --- | --- | --- |
| `[sql serverId]` | `Id` | `int` |

* `Id` 是自增主键（从您数据中的 1,2,3... 和 1021,1022... 可看出）
* 去重逻辑不变：**按 **`(ContestId, BankSiteId, ComplexPlanId)`** 分组，保留 **`Id`** 最小的一条**
