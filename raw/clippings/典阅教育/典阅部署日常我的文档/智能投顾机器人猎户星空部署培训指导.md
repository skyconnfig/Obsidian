# 2. 增加机器人的唤醒词
机器人端——三指下拉（密码是SN号的后四位）——设置——自定义唤醒词

![1776350370370-ca2c99a1-d5fe-44f5-8b4e-2776dc787038.png](./img/3DCysQSCf4wBq5Ms/1776350370370-ca2c99a1-d5fe-44f5-8b4e-2776dc787038-580257.png)

![1776350370941-78be7445-b8c7-4ea5-8018-6ddc20b5b147.png](./img/3DCysQSCf4wBq5Ms/1776350370941-78be7445-b8c7-4ea5-8018-6ddc20b5b147-989409.png)

1. 对于唤醒词的选择，建议是“ABAB”型的叠词，识别率较高，可以使用百度的唤醒词评估功能检测唤醒词的识别率：[https://ai.baidu.com/tech/speech/wake#tech-demo](https://ai.baidu.com/tech/speech/wake#tech-demo)
2. 唤醒词改了后，**小豹小豹的默认唤醒还是起作用的**，相当于**同时存在两个唤醒词**，默认“小豹小豹”和自定义唤醒词；
3. 默认唤醒词有经过模型训练，识别率比自定义唤醒词识别率高些，如果要做自定义唤醒词的训练，费用预计10W+；
4. 默认唤醒词唤醒率95%，自定义唤醒词的唤醒率为70%左右，为了使唤醒失败时机器人有回复，请在后台的问答库中增加该唤醒词的问答
