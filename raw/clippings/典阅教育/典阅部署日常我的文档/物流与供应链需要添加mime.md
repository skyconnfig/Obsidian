# 物流与供应链需要添加mime

<font style="color:rgb(0, 0, 0);">1.物流与供应链-3d-MeetingRoom</font>\ <font style="color:rgb(0, 0, 0);">2.物流与供应链-3d-WareHousing</font>\ <font style="color:rgb(0, 0, 0);">3.物流与供应链-3d-WarehousingOperations</font>

<font style="color:rgb(0, 0, 0);">上面三个3D场景的站点都需要加 MIME。</font>

<font style="color:rgb(0, 0, 0);">操作步骤：</font>\ <font style="color:rgb(0, 0, 0);">1、选中对应的站点，点击 `MIME 类型`，点击右上方 `添加`按钮</font>

<font style="color:rgb(0, 0, 0);">2、</font>\ <font style="color:rgb(0, 0, 0);">文件扩展名输入：.\*</font>\ <font style="color:rgb(0, 0, 0);">MIME 类型输入：application/octet-stream</font>

<font style="color:rgb(0, 0, 0);">点击`确认`</font>
