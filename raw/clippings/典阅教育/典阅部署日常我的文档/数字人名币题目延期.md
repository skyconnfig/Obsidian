# 数字人名币题目延期

### 先查询案列

1. **先备份** 或 在测试环境验证。
2. 可以先运行一个 `SELECT` 确认要更新的记录：

```bash
SELECT Id, Name, EndTime
FROM dg_Task
WHERE IsDel = 0 AND State = 1 AND TaskType = 1;
```

### 在更新案例时间

SQL 语句来将符合条件的记录（`State = 1`、`TaskType = 1`、`IsDel = 0`）的 `EndTime` 字段更新为 `2026-12-31 00:00:00.000`：

```bash
UPDATE dg_Task
SET EndTime = '2027-12-31 00:00:00.000'
WHERE IsDel = 0
  AND State = 1
  AND TaskType = 1;
```
