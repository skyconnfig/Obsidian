## 删除指定教师账号下面的学生的所有操作记录
查询指定老师下面的所有的学生账号 id

```plain
SELECT Id 
FROM [dbo].[bi_BankTeller]
WHERE Teller_No BETWEEN 's2023090501' AND 's2023090600' 
```
