# 服务启动

### <font style="color:rgb(0, 0, 0);">方法 1：放入「启动」文件夹（最简单，适用于普通程序）</font>

<font style="color:rgb(0, 0, 0);">Windows 「启动」文件夹会在用户登录后自动运行其中的快捷方式 / 程序，分「当前用户」和「所有用户」两种范围：</font>

#### <font style="color:rgb(0, 0, 0);">步骤 1：打开「启动」文件夹</font>

* **<font style="color:rgb(0, 0, 0) !important;">当前用户专属</font>**<font style="color:rgb(0, 0, 0);">（仅你登录时自启）：</font><font style="color:rgb(0, 0, 0);">按下</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">Win + R</font></code><font style="color:rgb(0, 0, 0);">，输入以下命令，回车打开：</font>**<font style="color:rgba(0, 0, 0, 0.85);">cmd</font>**

```plain
shell:startup
```

* **<font style="color:rgb(0, 0, 0) !important;">所有用户通用</font>**<font style="color:rgb(0, 0, 0);">（任何用户登录都自启，需管理员权限）：</font><font style="color:rgb(0, 0, 0);">按下</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">Win + R</font></code><font style="color:rgb(0, 0, 0);">，输入以下命令，回车打开：</font>**<font style="color:rgba(0, 0, 0, 0.85);">cmd</font>**

```plain
shell:common startup
```

#### <font style="color:rgb(0, 0, 0);">步骤 2：创建程序快捷方式并放入文件夹</font>

1. <font style="color:rgb(0, 0, 0);">找到 SHA 相关程序的</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">.exe</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">文件（如 HashCalc 路径：</font><code><font style="color:rgb(0, 0, 0);">D:\Software\HashCalc\HashCalc.exe</font></code><font style="color:rgb(0, 0, 0);">）；</font>
2. <font style="color:rgb(0, 0, 0);">右键</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">.exe</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">文件 → 「发送到」→ 「桌面（创建快捷方式）」；</font>
3. <font style="color:rgb(0, 0, 0);">将桌面生成的「HashCalc - 快捷方式」复制到步骤 1 打开的「启动」文件夹中；</font>
4. <font style="color:rgb(0, 0, 0);">重启电脑 / 注销重新登录，程序会自动启动。</font>

#### <font style="color:rgb(0, 0, 0);">验证：</font>

<font style="color:rgb(0, 0, 0);">登录后，可在「任务管理器」→ 「启动应用」中看到该程序，状态为「已启用」。</font>

### <font style="color:rgb(0, 0, 0);">方法 2：通过「任务计划程序」配置自启（适用于脚本 / 后台程序）</font>

<font style="color:rgb(0, 0, 0);">若需更灵活的自启规则（如开机后延迟启动、无界面运行、触发条件自定义），用「任务计划程序」：</font>

#### <font style="color:rgb(0, 0, 0);">步骤 1：打开任务计划程序</font>

* <font style="color:rgb(0, 0, 0);">按下</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">Win + R</font></code><font style="color:rgb(0, 0, 0);">，输入</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">taskschd.msc</font></code><font style="color:rgb(0, 0, 0);">，回车打开；</font>
* <font style="color:rgb(0, 0, 0);">左侧点击「任务计划程序库」→ 右侧点击「创建基本任务」。</font>

#### <font style="color:rgb(0, 0, 0);">步骤 2：配置基本任务向导</font>

1. **<font style="color:rgb(0, 0, 0) !important;">名称和描述</font>**<font style="color:rgb(0, 0, 0);">：输入名称（如「开机自启 SHA 校验工具」），点击「下一步」；</font>
2. **<font style="color:rgb(0, 0, 0) !important;">触发器</font>**<font style="color:rgb(0, 0, 0);">：选择「计算机启动时」（或「用户登录时」），点击「下一步」；</font>
3. **<font style="color:rgb(0, 0, 0) !important;">操作</font>**<font style="color:rgb(0, 0, 0);">：选择「启动程序」，点击「下一步」；</font>
4. **<font style="color:rgb(0, 0, 0) !important;">启动程序</font>**<font style="color:rgb(0, 0, 0);">：</font>
   * <font style="color:rgb(0, 0, 0);">点击「浏览」，选择 SHA 相关程序的</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">.exe</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">文件（如</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">HashCalc.exe</font></code><font style="color:rgb(0, 0, 0);">）；</font>
   * <font style="color:rgb(0, 0, 0);">「起始于」可填写程序所在文件夹路径（如</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">D:\Software\HashCalc</font></code><font style="color:rgb(0, 0, 0);">），点击「下一步」；</font>
5. **<font style="color:rgb(0, 0, 0) !important;">完成</font>**<font style="color:rgb(0, 0, 0);">：勾选「打开此任务属性的对话框」，点击「完成」。</font>

#### <font style="color:rgb(0, 0, 0);">步骤 3：优化任务属性（可选）</font>

1. <font style="color:rgb(0, 0, 0);">在任务属性窗口中，切换到「常规」选项卡：</font>
   * <font style="color:rgb(0, 0, 0);">勾选「使用最高权限运行」（若程序需要管理员权限）；</font>
   * <font style="color:rgb(0, 0, 0);">取消「仅在用户登录时运行」（若需开机无用户登录也自启，需管理员权限）；</font>
2. <font style="color:rgb(0, 0, 0);">切换到「设置」选项卡：</font>
   * <font style="color:rgb(0, 0, 0);">勾选「允许按需运行任务」「任务失败时重新启动」，点击「确定」。</font>

#### <font style="color:rgb(0, 0, 0);">验证：</font>

* <font style="color:rgb(0, 0, 0);">点击任务计划程序库中的任务，右侧点击「运行」，测试程序是否正常启动；</font>
* <font style="color:rgb(0, 0, 0);">重启电脑，程序会按配置自动运行。</font>

### <font style="color:rgb(0, 0, 0);">四、方法 3：通过 CMD 命令快速添加启动项（进阶）</font>

<font style="color:rgb(0, 0, 0);">若熟悉 CMD，可通过命令直接将程序快捷方式复制到「启动」文件夹：</font>

#### <font style="color:rgb(0, 0, 0);">1. 针对当前用户：</font>

**<font style="color:rgba(0, 0, 0, 0.85);">cmd</font>**

```plain
# 示例：将 HashCalc 快捷方式复制到当前用户启动文件夹
copy "D:\Software\HashCalc\HashCalc - 快捷方式.lnk" "%appdata%\Microsoft\Windows\Start Menu\Programs\Startup\"
```

#### <font style="color:rgb(0, 0, 0);">2. 针对所有用户（需管理员 CMD）：</font>

**<font style="color:rgba(0, 0, 0, 0.85);">cmd</font>**

```plain
# 示例：将 HashCalc 快捷方式复制到所有用户启动文件夹
copy "D:\Software\HashCalc\HashCalc - 快捷方式.lnk" "C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup\"
```

* <font style="color:rgb(0, 0, 0);">解释：</font>
  * <font style="color:rgb(0, 0, 0);">当前用户启动路径：</font><code><font style="color:rgb(0, 0, 0);">%appdata%\Microsoft\Windows\Start Menu\Programs\Startup</font></code>
  * <font style="color:rgb(0, 0, 0);">所有用户启动路径：</font><code><font style="color:rgb(0, 0, 0);">C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup</font></code>

### <font style="color:rgb(0, 0, 0);">五、常见问题排查</font>

1. **<font style="color:rgb(0, 0, 0) !important;">程序未自启</font>**<font style="color:rgb(0, 0, 0);">：</font>
   * <font style="color:rgb(0, 0, 0);">检查「启动」文件夹中的快捷方式是否有效（双击快捷方式能否打开程序）；</font>
   * <font style="color:rgb(0, 0, 0);">若为任务计划程序，查看「任务计划程序库」中任务的「上次运行结果」，是否提示权限不足（需勾选「使用最高权限运行」）。</font>
2. **<font style="color:rgb(0, 0, 0) !important;">自启程序有黑窗口（如批处理脚本）</font>**<font style="color:rgb(0, 0, 0);">：</font>
   * <font style="color:rgb(0, 0, 0);">若自启的是</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">.bat</font></code><font style="color:rgb(0, 0, 0);"> </font><font style="color:rgb(0, 0, 0);">脚本，在脚本开头添加</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">@echo off</font></code><font style="color:rgb(0, 0, 0);">，结尾添加</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">exit</font></code><font style="color:rgb(0, 0, 0);">，可隐藏黑窗口；</font>
   * <font style="color:rgb(0, 0, 0);">或在任务计划程序中，操作选择「启动程序」，「添加参数」中输入</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">/c 脚本路径.bat</font></code><font style="color:rgb(0, 0, 0);">，程序选择</font><font style="color:rgb(0, 0, 0);"> </font><code><font style="color:rgb(0, 0, 0);">cmd.exe</font></code><font style="color:rgb(0, 0, 0);">。</font>
3. **<font style="color:rgb(0, 0, 0) !important;">想禁用自启</font>**<font style="color:rgb(0, 0, 0);">：</font>
   * <font style="color:rgb(0, 0, 0);">「启动」文件夹：直接删除对应的快捷方式；</font>
   * <font style="color:rgb(0, 0, 0);">任务计划程序：右键任务 → 「禁用」或「删除」；</font>
   * <font style="color:rgb(0, 0, 0);">任务管理器：「启动应用」中找到程序，右键「禁用」。</font>
