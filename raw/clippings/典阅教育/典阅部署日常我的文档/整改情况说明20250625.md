# 整改情况说明20250625



整改情况说明

我公司收到漏洞通报后,立即组织整改,情况如下:

1. 整改经过：	

（一）漏洞定位与分析

接到通报后，我司第一时间确认漏洞场景：IIS 站点 bxds.hljzy.dianyueyun.com 的 Web 目录下存在源代码备份文件 bin.rar，可通过直接访问 URL 下载，导致源代码泄漏风险。

（二）具体整改操作

紧急移除备份文件  
登录 IIS 服务器，定位站点根目录（路径：[站点部署路径] ，如 C:\inetpub\wwwroot\bxds ），找到 bin.rar 文件并彻底删除，避免残留。

强化 Web 目录管理

梳理 IIS 站点所有文件，检查是否存在其他未授权备份文件（如 *.bak、*.zip 等 ），同步清理风险文件；调整 IIS 站点 “请求筛选” 规则，拦截对 *.rar、*.zip 等备份文件的访问（若业务需保留部分压缩包，通过权限配置限制下载 ）。流程优化与规范

在代码发布、站点维护流程中，新增 “Web 目录清理” 环节，强制清理未授权备份文件、临时文件；

明确规定：禁止将源代码备份文件存储在 Web 可访问目录，统一迁移至服务器非 Web 路径（如 D:\backup\ ），并通过权限管控（仅管理员可访问 ）降低泄漏风险。

1. 结果。目前已整改完毕。

目前已完成以下验证，确认漏洞修复：

访问 [http://bxds.hljzy.dianyueyun.com/bin.rar](http://bxds.hljzy.dianyueyun.com/bin.rar) ，返回 404 页面未找到，备份文件已删除；

检查 IIS 站点 Web 目录及关联存储路径，无其他备份文件暴露风险；

发布流程、站点维护规范已更新，从流程上避免同类问题复发。

1. 下一步，我们将定期自查，提高网络安全防范意识，防范类似事件再次发生。

定期自查与扫描：每月开展 IIS 站点专项安全检查，通过自动化脚本（如 PowerShell 遍历 Web 目录 ）+ 人工复核，排查备份文件、隐藏目录泄漏风险；

安全意识强化：组织研发、运维团队开展 “Web 站点安全配置” 培训，重点强调文件存储规范、权限管控要求；

应急响应优化：更新漏洞应急响应预案，针对源代码泄漏类问题，明确 “1 小时内定位、4 小时内处置、24 小时内复盘” 的时限要求，提升响应效率。
