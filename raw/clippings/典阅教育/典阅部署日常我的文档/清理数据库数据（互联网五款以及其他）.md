### 查询单个数据库的数据量
```sql
SELECT 
    SCHEMA_NAME(t.schema_id) + '.' + t.name AS [表名],
    c.name AS [时间字段名],
    ty.name AS [字段类型],
    p.rows AS [预估行数],
    'DELETE FROM ' + SCHEMA_NAME(t.schema_id) + '.' + t.name + ' WHERE ' + c.name + ' < ''2026-01-31'';' AS [生成的删除语句]
FROM sys.tables t
INNER JOIN sys.columns c ON t.object_id = c.object_id
INNER JOIN sys.types ty ON c.user_type_id = ty.user_type_id
INNER JOIN sys.partitions p ON t.object_id = p.object_id AND p.index_id IN (0, 1) -- 获取堆或聚集索引的行数
WHERE 
    t.type = 'U' -- 仅用户表
    AND ty.name IN ('datetime', 'datetime2', 'date', 'smalldatetime') -- 仅时间类型
ORDER BY 
    p.rows DESC; -- 按数据量从大到小排序
```
