## <font style="color:rgb(31, 35, 40);">Architecture</font><font style="color:rgb(31, 35, 40);"> </font><u><font style="color:rgb(31, 35, 40);">建筑</font></u>
<font style="color:rgb(31, 35, 40);">The application is built with a modular architecture designed for flexibility and performance:</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">该应用程序采用模块化架构构建，旨在实现灵活性和性能：</font></u>

```plain
┌───────────────────────────────────────────────────────────────────┐
│                    Website Extractor Application                   │
└───────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌───────────────────────────────────────────────────────────────────┐
│                           Flask Web Server                         │
└───────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌───────────────────────────────────────────────────────────────────┐
│                      Extraction Core Processes                     │
├───────────────┬──────────────────┬──────────────────┬─────────────┤
│  HTTP Client  │ Selenium Renderer │  Content Parser  │ Asset Saver │
│ (requests)    │ (WebDriver)       │ (BeautifulSoup)  │ (Zip)       │
└───────────────┴──────────────────┴──────────────────┴─────────────┘
```

### <font style="color:rgb(31, 35, 40);">Key Components</font><font style="color:rgb(31, 35, 40);"> </font><u><font style="color:rgb(31, 35, 40);">关键组件</font></u>
1. **<font style="color:rgb(31, 35, 40);">Flask Web Server</font>**<font style="color:rgb(31, 35, 40);">: Provides the user interface and handles HTTP requests</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">Flask Web 服务器：提供用户界面并处理 HTTP 请求</font></u>
2. **<font style="color:rgb(31, 35, 40);">HTTP Client</font>**<font style="color:rgb(31, 35, 40);">: Makes requests to fetch website content using the Requests library</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">HTTP 客户端：使用 Requests 库发出获取网站内容的请求</font></u>
3. **<font style="color:rgb(31, 35, 40);">Selenium Renderer</font>**<font style="color:rgb(31, 35, 40);">: Optional component for JavaScript rendering and dynamic content</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">Selenium Renderer：用于 JavaScript 渲染和动态内容的可选组件</font></u>
4. **<font style="color:rgb(31, 35, 40);">Content Parser</font>**<font style="color:rgb(31, 35, 40);">: Analyzes HTML to extract assets and structure using BeautifulSoup</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">内容解析器：使用 BeautifulSoup 分析 HTML 以提取资产和结构</font></u>
5. **<font style="color:rgb(31, 35, 40);">Asset Downloader</font>**<font style="color:rgb(31, 35, 40);">: Downloads all discovered assets with sophisticated retry logic</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">资产下载器：使用复杂的重试逻辑下载所有发现的资产</font></u>
6. **<font style="color:rgb(31, 35, 40);">ZIP Creator</font>**<font style="color:rgb(31, 35, 40);">: Packages everything into an organized downloadable archive</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">ZIP Creator：将所有内容打包到一个有组织的可下载存档中</font></u>

### <font style="color:rgb(31, 35, 40);">Processing Stages</font><font style="color:rgb(31, 35, 40);"> </font><u><font style="color:rgb(31, 35, 40);">加工阶段</font></u>
1. **<font style="color:rgb(31, 35, 40);">URL Submission</font>**<font style="color:rgb(31, 35, 40);">: User provides a URL and rendering options</font><font style="color:rgb(31, 35, 40);">

2. **<font style="color:rgb(31, 35, 40);">Content Acquisition</font>**<font style="color:rgb(31, 35, 40);">: HTML content is fetched (with or without JavaScript rendering)</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">内容获取：获取 HTML 内容（有或没有 JavaScript 渲染）</font></u>
3. **<font style="color:rgb(31, 35, 40);">Structure Analysis</font>**<font style="color:rgb(31, 35, 40);">: HTML is parsed and analyzed for assets and components</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">结构分析：对 HTML 进行解析和分析，以查找资产和组件</font></u>
4. **<font style="color:rgb(31, 35, 40);">Asset Discovery</font>**<font style="color:rgb(31, 35, 40);">: All linked resources are identified and categorized</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">资产发现：识别和分类所有链接的资源</font></u>
5. **<font style="color:rgb(31, 35, 40);">Parallel Downloading</font>**<font style="color:rgb(31, 35, 40);">: Assets are downloaded with optimized concurrent requests</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">并行下载：使用优化的并发请求下载资产</font></u>
6. **<font style="color:rgb(31, 35, 40);">Organization & Packaging</font>**<font style="color:rgb(31, 35, 40);">: Files are organized and compressed into a ZIP archive</font><font style="color:rgb(31, 35, 40);">  
</font><u><font style="color:rgb(31, 35, 40);">组织和打包：文件被组织并压缩成 ZIP 存档</font></u>
