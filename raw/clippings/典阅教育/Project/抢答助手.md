# 抢答助手

```python
大屏端（展示端）

题目展示 ：实时显示当前题目和选项

倒计时动画 ：题目答题时自动倒计时

答题人数统计 ：实时显示每个选项选择人数

排行榜 ：答题结束后，实时展示排名

2. 参赛端（手机/电脑）

加入游戏 ：输入房间号 / 扫码进入

答题界面 ：实时接收题目、倒计时、提交答案

反馈 ：答题结果正确/错误提示，个人积分更新

3. 管理端（主持人/老师）

题库管理 ：导入/编辑题目（Excel/JSON/后台UI）

比赛控制 ：开始/结束答题、切换题目、公布答案

实时监控 ：查看答题进度、正确率、用户数

⚙️ 技术架构推荐

前端

大屏端：React / Vue + WebSocket（全屏动画 + 排行榜 UI）

答题端：H5（手机友好），支持扫码进入

管理端：Web 后台（Vue/React + ElementUI/AntDesign）

后端

FastAPI（Python） 或 Node.js (Express/NestJS)

WebSocket（Socket.IO / FastAPI WebSocket）用于实时题目推送 & 答案收集

数据库：MySQL/PostgreSQL（存用户、成绩、题库）

Redis（缓存抢答/答题状态、排行榜）
```

```python
我将为三端（Web、移动、桌面）建立统一的“设计系统”目录与模块化架构，包含基础设计变量（Design Tokens）、主题样式、基础组件库和各端独立的设计规范文档。这样可在现有三个前端子项目（admin-client、participant-client、display-client）中复用统一风格，并按端做适配。

目录规划（将创建在 shared/design-system 下）：

foundations：跨端统一的设计变量与基础样式（颜色、间距、字号、阴影等）
themes：全局默认主题，支持后续扩展品牌主题
web：Web 端（管理端）适配的样式与基础组件
mobile：移动端（参赛端）适配的样式与基础组件（Tailwind/Vant 友好）
desktop：桌面/大屏端适配的样式与基础组件（ECharts/GSAP 场景友好）
README.md：总览与接入说明
说明：

统一使用 CSS 变量定义 Design Tokens，便于在 Vue、Tailwind、Element Plus、Vant、ECharts 等技术栈下直接使用。
每端提供 BaseButton 示例组件与端内规范文档，后续可以按此模式扩展其他组件（Card、Tag、Modal、ChartWrapper 等）。
文档中写明如何在 admin-client、participant-client、display-client 中引入这些样式与组件。
```

```python
开发一套支持线上线下混合使用的知识竞赛答题系统，满足以下目标：
- **大屏展示端**：实时呈现题目、倒计时、答题统计和排行榜，提高现场互动氛围。
- **参赛端（手机/电脑）**：提供便捷的扫码入场与答题体验，保证消息同步与反馈及时。
- **管理端**：覆盖题库、比赛流程、实时监控与数据复盘，简化运营成本。

### 项目范围
- 覆盖单场最多500人并发的快问快答比赛场景。
- 支持选择题、判断题、填空题三类题型，后续可扩展多媒体题。
- 对接短信/邮件等第三方通知方式留有扩展接口。
- 提供基础的运营数据导出能力（CSV/Excel）。

### 用户角色与核心需求
- **主持人/赛事运营**：快速创建比赛、控制进度、查看实时反馈。
- **参赛选手**：顺畅进入房间、获取题目、提交答案并查看成绩。
- **技术运维**：掌握系统运行状态，定位异常并快速修复。
- **内容管理员**：维护题库、管理标签与难度，保证题目质量。

## 功能模块

### 大屏端
- 题目展示：支持富文本、图片、音频的可选扩展，题目切换提供动效。
- 倒计时组件：默认30秒，可在管理端配置；支持临时暂停与重置。
- 答题统计：实时收集选项分布，提供柱状图/饼状图两种展示切换。
- 排行榜：按积分、正确率、平均答题时长等规则切换视图，支持TOP N设置。
- 赛事通知：滚动展示运营公告、系统提示或临时消息。

### 参赛端
- 房间接入：支持房间号、二维码两种方式；异常情况提示重连。
- 答题界面：自动推送题目，倒计时同步大屏；提供二次确认机制避免误触。
- 结果反馈：题目结束后显示正确答案、个人得分增量、累计排名。
- 个人中心：查看历史答题记录、积分、奖品信息（扩展需求）。
- 异常处理：网络中断自动重试，必要时支持切换至备用通道。

### 管理端
- 题库管理：Excel/JSON批量导入、标签管理、难度维护、题目上下架。
- 比赛控制：房间配置、题目顺序编排、开始/结束控制、答案公布策略。
- 实时监控：在线人数、提交进度、答题正确率、设备类型分布。
- 数据复盘：导出答题明细、榜单、题目统计，生成赛后报告。
- 权限管理：角色分级（管理员、主持人、出题人、观众）与操作审计日志。现在按照这些功能点给我写前端页面可以参考截图风格，但是三端所有风格需要统一
```
