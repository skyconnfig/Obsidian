```plain
我想搭建一个抢答器网站，网站风格赛博朋克风格，或者未来科技风格，可以自定义背景以及封面\                                                                                                                                                     │
│   我想要搭建一个抢答系统的网站                                                                                                                                                  │
│ 基于本地抢答器web系统的需求，我推荐以下技术栈：
支持手机端，电脑端以及pc端，支持execl导入题目，ppt导入，视频导入，文档导入，倒计时，计时功能

  前端

  - React + TypeScript - 组件化开发，类型安全
  - WebSocket - 实时通信，支持抢答功能
  - Tailwind CSS - 快速样式开发
  - Vite - 快速构建工具

  后端

  - Node.js + Express - 轻量级API服务
  - Socket.io - WebSocket封装，处理实时抢答逻辑
  - SQLite - 本地数据库，存储题目和成绩

  核心功能实现

  - 使用WebSocket实现毫秒级抢答响应
  - 前端状态管理处理多用户抢答状态
  - 后端队列管理确保抢答顺序公平性

  这个技术栈轻量、易部署，适合本地局域网使用，开发周期短且维护简单。                                                                                                                           │
│   接下来我们一步步规划，我使用的技术栈是否合理，你是否有更合适的技术栈推荐。ultra think   
```

```plain
### 认证模块 (/auth)
- POST /auth/login - 用户登录
- POST /auth/register - 用户注册
- POST /auth/refresh - 刷新令牌
- GET /auth/me - 获取当前用户信息
- POST /auth/logout - 用户登出
### 👥 用户管理模块 (/users)
- GET /users/profile - 获取当前用户信息
- PUT /users/profile - 更新用户信息
- GET /users/:id - 根据ID获取用户信息
- GET /users - 获取用户列表（分页）
### 🏠 房间管理模块 (/rooms)
- POST /rooms - 创建房间
- POST /rooms/join - 加入房间
- POST /rooms/:id/leave - 离开房间
- GET /rooms/:id - 获取房间详情
- GET /rooms/code/:code - 根据房间码获取房间信息
- PUT /rooms/:id - 更新房间信息
- DELETE /rooms/:id - 删除房间
- GET /rooms/my/hosted - 获取我创建的房间列表
- GET /rooms/my/joined - 获取我参与的房间列表
- GET /rooms/:id/participants - 获取房间参与者列表
### 📝 题目管理模块 (/questions)
- POST /questions - 创建题目
- GET /questions/:id - 获取题目详情
- GET /questions/room/:roomId - 获取房间的所有题目
- PUT /questions/:id - 更新题目
- DELETE /questions/:id - 删除题目
- POST /questions/:id/media - 上传题目媒体文件
- DELETE /questions/media/:mediaFileId - 删除媒体文件
- GET /questions/media/:mediaFileId/download - 下载媒体文件
- POST /questions/:id/answer - 提交答案
- GET /questions/:id/answers - 获取题目的所有答案
- GET /questions/stats/user/:userId/room/:roomId - 获取用户在房间中的答题统计
### 🛡️ 管理员模块 (/admin)
用户管理：

- GET /admin/users/stats - 获取用户统计信息
- GET /admin/users - 获取所有用户列表（分页、搜索）
- DELETE /admin/users/:id - 删除用户
- PUT /admin/users/:id/role - 更新用户角色
题目管理：

- GET /admin/questions/stats - 获取题目统计信息
- GET /admin/questions - 获取所有题目列表（分页）
- DELETE /admin/questions/:id - 删除题目
房间管理：

- GET /admin/rooms/stats - 获取房间统计信息
### 🏥 系统健康检查 (/health)
- GET /health - 健康检查
- GET /health/status - 系统状态
### 🔌 WebSocket实时通信
连接管理：

- join-room - 加入房间
- leave-room - 离开房间
实时交互：

- chat-message - 聊天消息
- buzz-in - 抢答
- answer-submit - 提交答案
- question-control - 题目控制（主持人专用）
实时事件：

- user-joined - 用户加入通知
- user-left - 用户离开通知
- room-users-update - 房间用户列表更新
- question-start - 题目开始
- question-end - 题目结束
- question-next - 下一题
- leaderboard-update - 排行榜更新
- system-message - 系统消息
```
