# 授权总结

```plain
这个`TimeMD5Controller`控制器主要用于处理软件时间权限（授权）相关的管理操作，基于ASP.NET MVC框架实现，核心功能包括数据展示、查询、导出、新增授权和删除授权等，具体总结如下：


### 1. 核心功能定位
用于管理软件的时间授权信息（如客户、项目、授权起止时间、密钥等），通过数据库操作、加密算法（DES）和Excel导出实现完整的授权生命周期管理。


### 2. 主要方法及功能

#### （1）`Index()`
- 作用：返回视图页面，用于展示软件时间权限的管理界面。


#### （2）`GetList()`
- 作用：根据前端查询条件（项目名称、客户名称、时间状态）获取分页数据列表。
- 细节：
  - 接收前端请求参数（如`selProject_sle`、`kehuName`、`seltimestate`）拼接SQL查询条件（区分“未到期”“即将到期”“已到期”状态，通过`datediff`计算时间差）。
  - 使用分页模型（`PageModel`）查询`tb_TimeMD5`表，关联`tb_Data_Dic`（获取项目名称）和`tb_User`（获取操作人）。
  - 返回序列化后的分页JSON数据。


#### （3）`GetExport()`
- 作用：根据查询条件将授权数据导出为Excel文件。
- 细节：
  - 基于与`GetList()`类似的查询条件，查询完整数据（包含客户、项目、时间、状态、密钥等信息）。
  - 通过`OfficeHelper`的`DtToExcel`方法将`DataTable`转换为Excel，定义表头（如“客户名称”“项目名称”等12个字段）。
  - 返回Excel文件路径（成功）或错误信息（失败）。


#### （4）`SetMd5()`
- 作用：新增软件时间授权记录，生成加密密钥并保存到数据库。
- 细节：
  - 接收前端参数（客户名称、项目、起止时间、联系人等）。
  - 根据项目类型（`text2`为1或2时）使用不同的加密内容（如“当前时间|到期时间”或直接“到期时间”），通过`Encrypt`方法（DES加密）生成密钥（`miyao`），密钥`SKey`为固定字符串+项目标识。
  - 将数据插入`tb_TimeMD5`表，返回操作结果（1成功，99失败）。


#### （5）`Del()`
- 作用：删除指定的授权记录。
- 细节：接收前端传递的`Ids`（主键集合），执行SQL删除操作，返回结果（1成功，99失败）。


#### （6）加密/解密工具方法
- `Encrypt(string pToEncrypt, string SKey)`：使用DES算法加密字符串（如授权时间），密钥和向量（IV）均为`SKey`的ASCII编码，返回十六进制加密结果。
- `Decrypt(string pToDecrypt, string SKey)`：DES解密方法，将加密的十六进制字符串还原为原始内容。


### 3. 核心依赖
- 数据库：操作`tb_TimeMD5`（授权主表）、`tb_Data_Dic`（数据字典，项目名称）、`tb_User`（用户表，操作人）。
- 工具类：`SqlHelper`（数据库操作）、`OfficeHelper`（Excel导出）、`PagerDal`（分页查询）。
- 加密算法：DES对称加密（用于生成授权密钥）。


### 4. 业务场景
主要用于企业内部管理软件的客户授权期限，支持查询、筛选、导出授权记录，以及新增/删除授权，通过加密密钥控制软件的使用时效。
```

```plain
	public static string Encrypt(string pToEncrypt, string SKey)
	{
		try
		{
			DESCryptoServiceProvider dESCryptoServiceProvider = new DESCryptoServiceProvider();
			byte[] bytes = Encoding.Default.GetBytes(pToEncrypt);
			dESCryptoServiceProvider.Key = Encoding.ASCII.GetBytes(SKey);
			dESCryptoServiceProvider.IV = Encoding.ASCII.GetBytes(SKey);
			MemoryStream memoryStream = new MemoryStream();
			CryptoStream cryptoStream = new CryptoStream(memoryStream, dESCryptoServiceProvider.CreateEncryptor(), CryptoStreamMode.Write);
			cryptoStream.Write(bytes, 0, bytes.Length);
			cryptoStream.FlushFinalBlock();
			StringBuilder stringBuilder = new StringBuilder();
			byte[] array = memoryStream.ToArray();
			foreach (byte b in array)
			{
				stringBuilder.AppendFormat("{0:X2}", b);
			}
			stringBuilder.ToString();
			return stringBuilder.ToString();
		}
		catch
		{
			return "0";
		}
	}

	public static string Decrypt(string pToDecrypt, string SKey)
	{
		try
		{
			DESCryptoServiceProvider dESCryptoServiceProvider = new DESCryptoServiceProvider();
			byte[] array = new byte[pToDecrypt.Length / 2];
			for (int i = 0; i < pToDecrypt.Length / 2; i++)
			{
				int num = Convert.ToInt32(pToDecrypt.Substring(i * 2, 2), 16);
				array[i] = (byte)num;
			}
			dESCryptoServiceProvider.Key = Encoding.ASCII.GetBytes(SKey);
			dESCryptoServiceProvider.IV = Encoding.ASCII.GetBytes(SKey);
			MemoryStream memoryStream = new MemoryStream();
			CryptoStream cryptoStream = new CryptoStream(memoryStream, dESCryptoServiceProvider.CreateDecryptor(), CryptoStreamMode.Write);
			cryptoStream.Write(array, 0, array.Length);
			cryptoStream.FlushFinalBlock();
			StringBuilder stringBuilder = new StringBuilder();
			return Encoding.Default.GetString(memoryStream.ToArray());
		}
		catch (Exception)
		{
			return "0";
		}
	}
```
