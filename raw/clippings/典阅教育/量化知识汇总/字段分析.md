### 📌 2. 复权价格字段（核心中的核心）

| 字段名 | 中文说明 | 计算逻辑 | 存储建议 |
| --- | --- | --- | --- |
| `open_hfq` | 开盘价（后复权） | `open * adj_factor` | ✅ 存储（重要） |
| `high_hfq` | 最高价（后复权） | `high * adj_factor` | ✅ 存储 |
| `low_hfq` | 最低价（后复权） | `low * adj_factor` | ✅ 存储 |
| `close_hfq` | 收盘价（后复权） | `close * adj_factor` | ✅ 存储 |
| `open_qfq` | 开盘价（前复权） | `open / adj_factor` | ✅ 存储 |
| `high_qfq` | 最高价（前复权） | `high / adj_factor` | ✅ 存储 |
| `low_qfq` | 最低价（前复权） | `low / adj_factor` | ✅ 存储 |
| `close_qfq` | 收盘价（前复权） | `close / adj_factor` | ✅ 存储 |

> ✅ **关键说明**：
>
> * **后复权（hfq）**：适用于**长期持有者**，反映真实收益（含分红再投资）
> * **前复权（qfq）**：适用于**技术分析**，价格连续，便于画图
> * `adj_factor` 是**复权系数**，由数据源提供，是复权计算的唯一依据
> * **强烈建议存储 hfq 和 qfq**，否则无法做回测！

### 📌 4. 技术指标字段（核心策略基础）

这些是**技术分析**的基石，绝大多数可由 `close, high, low, vol` 计算得出。

#### ✅ 标准技术指标（推荐用 TA-Lib 计算）

| 指标名 | 中文名 | 计算公式 | 实现工具 | 存储建议 |
| --- | --- | --- | --- | --- |
| `ma_bfq_5` | 简单移动平均（5日） | `avg(close_qfq[1:5])` | `talib.SMA()` | ❌ 动态计算 |
| `ma_bfq_10` | 简单移动平均（10日） | `avg(close_qfq[1:10])` | `talib.SMA()` | ❌ |
| `ma_bfq_20` | 简单移动平均（20日） | `avg(close_qfq[1:20])` | `talib.SMA()` | ❌ |
| `ma_bfq_60` | 简单移动平均（60日） | `avg(close_qfq[1:60])` | `talib.SMA()` | ❌ |
| `ma_bfq_250` | 简单移动平均（250日） | `avg(close_qfq[1:250])` | `talib.SMA()` | ❌ |
| `ema_bfq_10` | 指数移动平均（10日） | `EMA(close_qfq, 10)` | `talib.EMA()` | ❌ |
| `ema_bfq_20` | 指数移动平均（20日） | `EMA(close_qfq, 20)` | `talib.EMA()` | ❌ |
| `macd_dif_bfq` | MACD-DIF | `EMA(12) - EMA(26)` | `talib.MACD()` | ❌ |
| `macd_dea_bfq` | MACD-DEA | `EMA(DIF, 9)` | `talib.MACD()` | ❌ |
| `macd_bfq` | MACD柱 | `DIF - DEA` | `talib.MACD()` | ❌ |
| `rsi_bfq_12` | RSI（12日） | `100 - 100/(1 + RS)`，RS=平均涨幅/平均跌幅 | `talib.RSI()` | ❌ |
| `boll_upper_bfq` | 布林带上轨 | `MA + 2 * STD` | `talib.BBANDS()` | ❌ |
| `boll_lower_bfq` | 布林带下轨 | `MA - 2 * STD` | `talib.BBANDS()` | ❌ |
| `kdj_k_bfq` | KDJ-K | `K = 2/3 * prev_K + 1/3 * RSV` | `talib.STOCH()` | ❌ |
| `kdj_d_bfq` | KDJ-D | `D = 2/3 * prev_D + 1/3 * K` | `talib.STOCH()` | ❌ |
| `kdj_j_bfq` | KDJ-J | `3*K - 2*D` | 自定义 | ❌ |
| `cci_bfq` | CCI | `(TP - MA) / (0.015 * MD)` | `talib.CCI()` | ❌ |
| `atr_bfq` | ATR（14日） | `avg(TR, 14)`，TR = max(H-L, H-PC, PC-L) | `talib.ATR()` | ❌ |
| `volatility` | 波动率（10日） | `std(log(close/close_lag), 10)` | 自定义 | ❌ |

> ✅ **强烈建议**：
>
> * **不要存储这些技术指标！**
> * 使用 **TA-Lib（Python）** 或 **Talib.NET（C#）** 在查询时动态计算
> * 存储 `close_qfq` + `volume` 就够了，所有指标可即时生成
> * 存储会占用大量空间，且更新困难

> 🚫 **不推荐**：把所有 100+ 个指标都存进数据库 → **灾难级冗余**

### 📌 6. 市场情绪与统计指标

| 字段名 | 中文名 | 计算逻辑 | 建议 |
| --- | --- | --- | --- |
| `updays` | 连涨天数 | 统计连续 `close > pre_close` 的天数 | ❌ 动态计算 |

> ✅ **建议**：\
> 这些是**序列统计特征**，适合在策略回测时用 `pandas` 或 `polars` 计算，例如：

```python
df['updays'] = (df['close'] > df['close'].shift(1)).astype(int).groupby((df['close'] <= df['close'].shift(1)).cumsum()).cumsum()
```

## ✅ 三、最终建议：数据库设计最佳实践

| 类别 | 是否存储 | 原因 |
| --- | --- | --- |
| ✅ 基础价格（open, high, low, close） | ✅ 存储 | 核心数据，不可丢失 |
| ✅ 复权因子（adj\_factor） | ✅ 存储 | 复权计算的唯一依据 |
| ✅ 复权价格（hfq/qfq） | ✅ 存储 | 避免重复计算，提升性能 |
| ✅ 成交量、成交额、股本 | ✅ 存储 | 基础量能与市值计算依据 |
| ✅ 市值、PE、PB、股息率 | ✅ 存储（按日/周） | 用于基本面筛选，更新频率低 |
| ❌ 技术指标（MA, EMA, MACD, RSI...） | ❌ **不要存储** | 可瞬时计算，存储浪费空间 |
| ❌ 情绪指标（updays, bias, vr...） | ❌ **不要存储** | 动态计算更灵活 |
| ✅ 数据更新日志、错误日志 | ✅ 存储 | 用于监控数据质量 |
