# 我的博客

  
我们直接用：

+ [GitHub](https://github.com?utm_source=chatgpt.com)
+ [GitHub Pages](https://pages.github.com/?utm_source=chatgpt.com)
+  Markdown 文档 
+  静态博客框架（Hexo） 

做一个类似“语雀”的知识库网站。

我一步一步教你，从 0 开始。

---

# 第一步：安装 Node.js
因为 Hexo 需要 Node.js。

下载：

[Node.js 官网](https://nodejs.org/zh-cn?utm_source=chatgpt.com)

下载：

```plain
LTS 长期支持版
```

安装时一直下一步即可。

安装完成后：

打开 CMD 或 PowerShell 输入：

```plain
node -v
npm -v
```

出现版本号说明成功。

例如：

```plain
v22.x.x
10.x.x
```

---

# 第二步：安装 Git
下载：

[Git 官网](https://git-scm.com/download/win?utm_source=chatgpt.com)

安装完成后：

输入：

```plain
git --version
```

---

# 第三步：注册 GitHub
注册：

[GitHub](https://github.com/signup?utm_source=chatgpt.com)

注册完成后登录。

---

# 第四步：创建网站仓库
进入：

```plain
New repository
```

仓库名填写：

```plain
你的用户名.github.io
```

例如：

```plain
darktor.github.io
```

⚠️ 注意：

必须：

```plain
用户名.github.io
```

仓库：

+  Public（公开） 
+  勾选 README 

创建完成。

---

# 第五步：安装 Hexo
打开 CMD：

创建项目目录：

```plain
mkdir myblog
cd myblog
```

安装 Hexo：

```plain
npm install -g hexo-cli
```

检查：

```plain
hexo -v
```

---

# 第六步：初始化博客
执行：

```plain
hexo init
npm install
```

启动本地预览：

```plain
hexo server
```

浏览器打开：

```plain
http://localhost:4000
```

你会看到博客。

---

# 第七步：安装 GitHub 部署插件
继续输入：

```plain
npm install hexo-deployer-git --save
```

---

# 第八步：配置 GitHub Pages
打开：

```plain
myblog/_config.yml
```

找到最后：

```plain
deploy:
```

改成：

```plain
deploy:
  type: git
  repo: https://github.com/你的GitHub用户名/你的用户名.github.io.git
  branch: main
```

例如：

```plain
deploy:
  type: git
  repo: https://github.com/darktor/darktor.github.io.git
  branch: main
```

---

# 第九步：生成网站
执行：

```plain
hexo clean
hexo g
hexo d
```

第一次会要求 GitHub 登录。

完成后等待 1~2 分钟。

访问：

```plain
https://你的用户名.github.io
```

成功。

---

# 第十步：发布文章（Markdown）
进入：

```plain
source/_posts
```

新建：

```plain
hello.md
```

写：

```plain
# 我的第一篇文章

这是我的知识库网站。

## AI工具推荐

这里可以写教程、资源、引流内容。
```

保存。

重新生成：

```plain
hexo g
hexo d
```

网站更新。

---

# 第十一步：换漂亮主题（推荐）
推荐：

## NexT（最稳）
[NexT GitHub](https://github.com/next-theme/hexo-theme-next?utm_source=chatgpt.com)

特点：

+  国内访问快 
+  SEO 好 
+  适合广告 
+  类似知识库 

安装：

进入博客目录：

```plain
git clone https://github.com/next-theme/hexo-theme-next themes/next
```

修改：

```plain
_config.yml
```

找到：

```plain
theme: landscape
```

改成：

```plain
theme: next
```

重新：

```plain
hexo clean
hexo g
hexo d
```
