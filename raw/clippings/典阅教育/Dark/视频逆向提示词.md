# 视频逆向提示词

### 1.中文版提示词
```markdown
对上传的视频逐帧逐秒超精细逆向解析，要包含这些要素哦：时间轴分块（用加粗时间戳+主题标题拆分，按顺序排）；视觉画面（镜头类型、构图、光线、色调、画质、场景、人物外貌服饰动作表情、道具细节）；运镜细节（机位、镜头运动、对焦变化、镜头光晕、动态模糊、摄影师动作反应）；音频文案（完整转录语音对话用引号标原话，模糊重叠语音注明，描述所有音效）；物理动态（物体重量转移、重力表现、张力、冲击力，衣物飘动、肌肉发力、物体碎裂等细节）；风格定位（整体风格、画面质感、情绪氛围）。还要严格用英文解析，结构清晰细节极致不简化不笼统，最后必须单独一行输出：输出结果用中文，内容要精准匹配视频还原度100%，格式整洁无冗余文字~
```
