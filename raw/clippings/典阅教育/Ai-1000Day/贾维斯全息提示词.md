# 贾维斯全息提示词

# 初版提示词（**@Xuan酱博主分享**）
```plain
### 角色设定：世界级创意前端工程师
- 核心技能：精通 WebGL（Three.js/@react-three/fiber）、计算机视觉（MediaPipe）、赛博朋克 UI 设计
- 技术栈专长：React + TypeScript + Vite、@react-three/postprocessing、@mediapipe/tasks-vision、Tailwind CSS
- 任务目标：开发单文件 React 应用，复刻钢铁侠 JARVIS 风格全息 HUD 交互界面（融合摄像头实景、3D 全息地球、手势交互）

### 详细功能与技术要求
#### 1. 视觉风格（Visuals）
- 背景：全屏实时摄像头画面（保留色彩，降低亮度/提高对比度）
- UI 主题：青色（#00FFFF）为主色调，包含扫描线、发光文本、虚线边框、动态数据流、跳动进度条
- HUD 布局：
  - 左上角：核心系统状态 + 随机滚动十六进制代码
  - 右上角："贾维斯 (J.A.R.V.I.S)" 大号标题 + 当前时间 + 系统脉冲动画
  - 左下角：手部追踪状态指示器
  - 右侧悬浮窗：可拖拽"地理情报分析面板"（显示当前地球面向大洲及虚构扫描数据）

#### 2. 3D 全息地球（Three.js）
- 位置：屏幕左侧（x = -1.0）
- 材质：TextureLoader 加载地球镜面贴图，AdditiveBlending 加法混合（陆地发光、海洋透明）
- 装饰：外层包裹旋转线框球体 + 行星环
- 状态反馈：根据旋转角度实时计算面向大洲（美洲/太平洋/亚洲/欧洲/非洲），回调至 UI 层

#### 3. 交互逻辑（核心算法）
- 手部追踪：基于 MediaPipe 实现双手骨骼识别
- 左半屏交互（控制地球）：
  - 旋转：左手手掌 X/Y 轴移动控制
  - 缩放：左手拇指与食指距离检测（张开=放大，捏合=缩小）
- 右半屏交互（控制悬浮窗）：
  - 拖拽：右手捏合状态（拇指食指距离<阈值）时，面板跟随右手位置移动；松开停止

#### 4. 代码结构与优化
- 性能优化：高频计算（MediaPipe 循环、3D 旋转）使用 useRef + requestAnimationFrame，避免频繁重渲染
- 骨骼绘制：2D Canvas 层实时绘制青色发光手部骨骼连线
- 界面语言：全部文本使用中文
```

# 进阶版提示词(老雷整理)
```plain
### 角色设定
你是资深前端工程师，任务是“复刻并重现现有 JARVIS 全息 HUD 项目”的代码与行为。务必按下述结构、库版本、交互参数与视觉规范生成完整可运行的 Vite + React + TS 项目。

### 项目结构与入口：
- 根入口：`index.html` 使用 Tailwind CDN 与 ImportMap（无需本地 Tailwind 配置）
- 前端入口：`index.tsx` 挂载 `App` 到 `#root`
- 主界面：`App.tsx` 包含“启动页 → Intro → 主界面”三段式流程
- 组件：`components/VideoFeed.tsx`、`components/HolographicEarth.tsx`、`components/HUDOverlay.tsx`、`components/JarvisIntro.tsx`
- 服务：`services/mediapipeService.ts`（手势识别初始化），`services/soundService.ts`（Web Audio 程序化音效 + TTS）
- 类型：`types.ts`（Landmark、HandInteractionData、RegionName 等）
- 模型资源：`modules/gesture_recognizer.task`（MediaPipe 手势模型，支持本地/远程双路径）
- 构建：`vite.config.ts`（别名 `@` 指向项目根，`assetsInclude` 包含 `.task`）

### 库与版本（严格匹配）：
- `react@18.3.1`、`react-dom@18.3.1`
- `three@0.164.1`
- `@react-three/fiber@8.16.6`、`@react-three/drei@9.105.6`
- `@react-three/postprocessing@2.16.2`、`postprocessing@6.35.4`
- `@mediapipe/tasks-vision@0.10.9`
- `maath@^0.10.8`
- 开发：`vite@^6.2.0`、`@vitejs/plugin-react@^5.0.0`、`typescript@~5.8.2`

### 启动与流程（必须一致）：
- 首次点击“初始化 J.A.R.V.I.S.”触发音频权限与启动音效；随后显示三段加载条文案（系统启动/加载神经网络/身份验证）
- 约 2.5s 后进入 `JarvisIntro`，展示同心环与发光标题，同时 TTS 播放 “Hello. I am Jarvis.”
- Intro 后进入主界面并开启低音环境嗡鸣

### 视觉与 HUD（中文界面）：
- 背景：摄像头画面（镜像、降低亮度、提高对比度，带轻微灰度），带扫描线与暗角遮罩
- 主色：`#00F0FF`（holo-cyan），辅色：`klein-blue`、`holo-blue`、`alert-red`
- 顶部左侧：系统状态牌与随机十六进制滚动日志
- 顶部右侧：大号 “J.A.R.V.I.S.” 标题 + “实时画面”红色指示 + 高频时钟
- 左侧中段：双圆形仪表（Primary Storage 74%、Power Cells 98%）
- 左下：目录树（RainMeter/Resources/Browser/Themes + Emergency）
- 右侧中段：同心旋转环（Arc Reactor/Compass）+ 简要数据（O2/TEMP）
- 右下：外部数据源列表（gmail/wikipedia/...），含状态点与进度条

### 3D 全息地球（R3F + Three + PostProcessing）：
- 地球材质：`meshPhongMaterial`，`map + normalMap + specularMap`，`AdditiveBlending` 叠加发光（发光映射陆地）
- 包装：云层球（轻透明）、反向旋转线框（icosahedron wireframe）、外环（ring）、环绕卫星粒子（`Points` + `PointMaterial`）
- 光效：Bloom（`@react-three/postprocessing`）营造全息感
- 旋转面向区域判定并回传中文地区名（美洲/太平洋/亚洲/欧洲/非洲）
- 左手展开度控制各层半径与自转速度差异，右手控制地球 yaw/pitch

### 手势与交互（MediaPipe 双手）：
- 识别：`GestureRecognizer`，`numHands = 2`，`runningMode = VIDEO`，首选本地模型，失败走远程 CDN；WASM 优先 jsDelivr，失败切 unpkg
- 左手展开度（expansionFactor）：按拇指尖(4)与食指尖(8)距离归一化；`minPinch=0.02 / maxPinch=0.18` 映射 0~1
- 右手旋转控制：取中指 MCP(9)位置映射 `x∈[-1,1]` 控水平旋转、`y∈[-1,1]` 控俯仰倾斜
- 右手捏合：拇指尖(4)与食指尖(8)距离 `<0.05` 判定 pinch，显示悬浮情报面板并绘制连接线，松开隐藏
- 左手腕附近绘制圆形“展开度/引擎出力”仪表盘，超过 95% 显示红色“最大输出”
- 指尖绘制旋转锁定圈；骨架用虚线；掌心显示手 ID 文案

### 地形切换与战术视图：
- 左手展开度平滑过渡（指数滤波），`exp > 0.4` 起对地球淡出，`exp > 0.55` 触发“地形模式”音效并显示战术地形
- 战术地形：高细分 `PlaneGeometry` 用简易 FBM/正弦组合生成起伏；线框+半透明填充；同心雷达环随时间衰变透明；波峰处悬浮目标标记（圈、十字、竖线）
- 右手旋转同样影响战术地形整体旋转/倾斜，以保持技术感

### 程序化音效（Web Audio + TTS）：
- 点击/细微交互：`playBlip()`
- 机械锁定/释放：`playLock()` / `playRelease()` 对应 pinch 显示/隐藏
- 展开度移动：`playServo(intensity)` 按帧变化触发短粒度电机感
- 地形切换：`playMapSwitch()`
- 环境：`playAmbientHum()` 持续低频嗡鸣
- TTS：`speak("Hello. I am Jarvis.")`，偏英式男声；在引导完成后播放

### 性能与渲染策略：
- 摄像头与识别：`requestAnimationFrame` 驱动，`video.currentTime` 比较防止重复推理；手动取消/释放摄像头轨道
- 3D：`useFrame` 更新旋转/缩放/淡入淡出，粒子与环轻量动画；`gl.antialias=false` 以配合后期
- UI Canvas：自适应窗口大小，合并绘制，减少状态更新
- 降级：摄像头或音频失败时保留 UI 与动画，给出日志提示

### 输出要求：
- 提供完整可运行项目代码（文件按上述名称与路径），以及依赖安装与运行命令（`npm i && npm run dev`）
- 禁止引入未声明库；严格匹配版本；保留中文 UI 文案与数值
- 保留镜像视频（水平反转）与滤镜：对比度 125%、亮度 75%、轻度灰度
- 所有阈值与参数按上述数值与逻辑实现

### 验收标准：
- 启动页三阶段进度与 TTS Intro 后进入主界面
- 背景摄像头 + HUD 布局、扫描线与暗角正常显示
- 地球具备云层/线框/外环/粒子与 Bloom；区域判定回传中文名
- 左手展开度控制层间半径与速度；阈值 0.55 切换战术地形并有音效
- 右手旋转控制有效；捏合显示情报面板，松开隐藏并触发锁定/释放音
- 2D Canvas 绘制骨架、指尖锁定圈、左腕圆形仪表盘；UI文案全中文
- 程序化音效均可听到；环境嗡鸣持续；整体 60FPS 目标，低端 ≥30FPS
```
