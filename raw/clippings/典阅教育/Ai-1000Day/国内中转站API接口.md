# 国内中转站API 接口

### 国内中转站API 接口
购买中转站的模型接口，我为了大家方便学习，自建了一个中转站，方便大家国内直接使用，并且价格比官方便宜很多。（也顺便有一点微薄盈利）

1.打开链接：http://api.xueai.me/ 使用GitHub账号或邮箱注册账号

2.点击控制台，点击API，点击添加令牌，

![1757637965638-d66c6ed2-5e8e-4442-acae-182ab033ab89.png](./img/B4gOKNrxgCBzW5-f/1757637965638-d66c6ed2-5e8e-4442-acae-182ab033ab89-549149.png)

![1757637965473-3bd2c7cb-6991-443c-927b-d7389aeb6ba9.png](./img/B4gOKNrxgCBzW5-f/1757637965473-3bd2c7cb-6991-443c-927b-d7389aeb6ba9-234731.png)

3.设置名称，分组选择官转克劳德2，额度无限制，点击提交（当然这里有很多分组，有很多其他模型，我们暂时先忽略）

![1757637965506-2309c857-2475-49f5-9adb-ae9f66a4484a.png](./img/B4gOKNrxgCBzW5-f/1757637965506-2309c857-2475-49f5-9adb-ae9f66a4484a-915789.png)

4.获取api key

![1757637965573-4c3e4ba3-2dd4-4b19-b6df-af5ad699c28e.png](./img/B4gOKNrxgCBzW5-f/1757637965573-4c3e4ba3-2dd4-4b19-b6df-af5ad699c28e-029891.png)

5.充值，可以固定金额充值，可以自定义金额。

![1757637965634-e4398898-2ff5-46ee-8c3e-35e0b0acc666.png](./img/B4gOKNrxgCBzW5-f/1757637965634-e4398898-2ff5-46ee-8c3e-35e0b0acc666-146910.png)

6.关于费用计算，点击导航栏的“定价”，<font style="color:rgb(143,149,158);">按量计费费用 = 分组倍率 × 模型倍率 × （提示token数 + 补全token数 × 补全倍率）/ 500000 （单位：人民币）</font>

**<font style="color:rgb(216,57,49);">注意不要大额充值，因为不能退款</font>**
