# 比赛系统设计

```python
基于你提供的需求，下面是一个更为详细的系统设计，包括用户登录、权限管理、管理员端功能、考核任务管理等模块。

### 1. **登录系统与权限管理**

#### 1.1 **登录界面**

* **字段**：用户名、密码、记住密码（选项）、注册按钮
* **功能**：

  * **用户名和密码**：用户输入后，系统会验证是否正确。
  * **记住密码**：如果选中该项，系统会存储用户名和密码，在下次登录时自动填充。
  * **注册功能**：提供新用户注册界面，用户可选择注册为学生代表、老师、裁判员或管理员。

#### 1.2 **用户类型与权限**

* **用户类型**：系统有四种用户角色：

  * **管理员**：拥有最高权限，能够管理用户、比赛内容、评分规则等。
  * **老师**：可以查看比赛进展、成绩及相关内容，但不能进行系统管理操作。
  * **裁判员**：负责评分、扣分等操作，必须输入扣分数（如不扣分则填写`0`，扣分100分则从总分扣除，不能算加分）。
  * **学生代表**：参与比赛的学生，能够查看自己的成绩和比赛信息。

### 2. **后台管理界面**

#### 2.1 **管理员权限**

* **管理员登录**：管理员使用`admin`用户登录管理员界面，拥有完整权限。
* **管理员界面功能**：

  * **用户管理**：包括新增、修改、删除用户，激活或关闭用户账号（如锁定）。
  * **批量操作**：支持批量删除用户和其他批量管理操作。
  * **搜索功能**：

    * **模糊搜索**：支持用户信息的模糊搜索（如按用户名、邮箱搜索）。
    * **定向搜索**：支持根据特定条件（如用户类型、状态等）进行定向搜索。

#### 2.2 **考核任务管理**

* **考核计划管理**：

  * 管理员可以设置并管理不同的考核计划，定义每个计划的基本信息（如考核名称、目标、时间、参与者等）。
* **考核任务设置**：

  * 管理员可以为考核计划分配具体的考核任务（如理论考试、实操考核等）。
  * 设置考核任务的详细内容、评分标准、任务要求等。
* **考核时间设置**：

  * 管理员可以设置每个考核任务的时间限制（如考试时间、实操时间等），以及任务的开始和结束时间。

#### 2.3 **裁判员功能**

* **扣分功能**：裁判员可以对参赛者进行扣分操作。系统会自动根据裁判员的输入来调整参赛者的总分。

  * **扣分**：裁判员输入扣分数（如100分），系统会从参赛者的总分中扣除，不能加分。如果填写0，则不扣分。
  * **无加分**：如果有加分项，则不计入最终得分。

### 3. **系统功能设计**

#### 3.1 **题库与评分管理**

* **题库管理**：管理员可管理比赛的题库，支持Excel导入和导出，方便管理和更新题目。
* **自动评分与人工评分**：理论部分自动评分，实操部分由裁判员人工评分，系统记录裁判员的评分数据。

#### 3.2 **用户管理**

* **用户信息**：管理员能够查看所有用户信息，执行增删改查操作。
* **用户角色分配**：管理员为每个用户分配角色（管理员、老师、裁判员、学生代表）。

#### 3.3 **积分管理与结果计算**

* **比赛得分**：系统根据参赛者的表现自动计算成绩，裁判员可进行加分或扣分操作。
* **最终成绩**：裁判员的扣分操作会实时反映在系统中，最终成绩会在比赛结束后生成。

### 4. **技术栈与实现**

#### 4.1 **前端技术**

* **HTML5、CSS3、JavaScript（React/Vue）**：实现登录界面、管理员界面以及用户交互。
* **WebSocket**：用于实时更新比赛进度和成绩。
* **Excel导入导出**：利用`xlsx`库（前端）或`openpyxl`（后端）来处理Excel文件的导入导出。

#### 4.2 **后端技术**

* **Node.js + Express 或 Python + Django**：实现API服务，处理用户登录、权限管理、成绩计算、题库管理等功能。
* **WebSocket**：用于实时推送比赛进度和成绩更新。

#### 4.3 **数据库设计**

* **MySQL**：

  * **用户表**：存储所有用户的基本信息，包括用户名、密码、角色、状态等。
  * **题库表**：存储比赛题目、答案、类型等。
  * **成绩表**：记录参赛者的理论成绩、实操成绩及扣分信息。
  * **考核任务表**：存储考核计划和任务的相关信息。

#### 4.4 **安全性设计**

* **加密**：密码存储时使用哈希加密，避免明文存储。
* **权限管理**：确保不同角色的用户只能访问相应权限的功能。

### 5. **流程示意**

1. **用户登录**：

   * 用户输入用户名和密码登录系统，系统验证权限，成功后跳转至对应角色的首页。
2. **管理员操作**：

   * 管理员可以管理用户、设置考核计划、分配任务、修改任务时间等。
   * 可以批量删除用户，或按条件搜索和删除。
3. **裁判员操作**：

   * 裁判员对参赛者进行评分，输入扣分项（如没有加分则填0，扣分100分从总分扣除）。
4. **学生代表查看**：

   * 学生代表可以查看自己的成绩和比赛信息。

### 6. **用户界面设计**

* **登录界面**：包括用户名、密码、记住密码、注册功能。
* **管理员界面**：提供功能按钮来管理用户、考核任务等。
* **裁判员界面**：提供输入框和按钮来进行扣分操作。
* **学生代表界面**：提供成绩查询和比赛进度查看功能。
```
