# 最新开源大语言模型GLM-4模型详细教程—环境配置+模型微调+模型部署+效果展示

### 1.环境安装
安装建议通过 Conda 进行环境管理。执行以下命令新建一个 conda 环境并安装所需依赖：

```powershell
conda create -n glm-4-demo python=3.11.7
conda activate glm-4-demo
pip install -r requirements.txt
```

请注意，本项目需要 python3.10 或者更高版本，此外，使用 Code Interpreter 还需要安装具 jupter 内核：

```powershell
ipython kernel install --name glm-4-demo --user
```
