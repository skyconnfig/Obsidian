# 安装coqui-aiTTS

### 1.克隆地址
```plain
git clone https://github.com/coqui-ai/TTS
```

### 2.新建 python 虚拟环境
```plain
python -m venv venv
```

### 3.免证书安装
```plain
pip install -e .[all,dev,notebooks] --trusted-host mirrors.aliyun.com --trusted-host pypi.org --trusted-host pypi.python.org --trusted-host files.pythonhosted.org
```
