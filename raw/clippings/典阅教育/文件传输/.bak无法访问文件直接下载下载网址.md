***

### 🔒 为什么 `.bak` 无法访问？

IIS 默认配置中，**未映射 MIME 类型的文件扩展名会被拒绝访问**，并返回 **HTTP 404.3 - Not Found** 或 **404.7 - File extension denied** 错误。

`.bak` 属于“未注册 MIME 类型”的扩展名，且 IIS 的 **请求筛选（Request Filtering）** 功能通常会显式阻止此类扩展名。

***

### ✅ 如果你确实需要远程访问 `.bak` 文件（仅限可信内网或临时调试）

> ⚠️ **强烈不建议在生产环境开放 **`.bak`** 访问权限**，因为这可能导致数据库备份、配置文件等敏感信息泄露！

#### 方法一：为 `.bak` 添加 MIME 类型（推荐用于临时调试）

1. 打开 **IIS 管理器**；
2. 选择你的站点（或根服务器）；
3. 双击 **“MIME 类型”**；
4. 点击右侧 **“添加...”**；
5. 输入：
   * **扩展名**：`.bak`
   * **MIME 类型**：`application/octet-stream`（通用二进制流）
6. 点击 **确定**。

> ✅ 完成后，访问 `http://yourdomain/file.bak` 将会触发浏览器下载。

#### 方法二：修改请求筛选规则（谨慎操作）

1. 在 IIS 管理器中，进入站点 → **“请求筛选”**；
2. 切换到 **“文件扩展名”** 标签；
3. 查看是否有一条 **拒绝（Deny）** 规则包含 `.bak`；
4. 如果有，**选中它 → 右键 → 删除**；
5. 或者点击右侧 **“编辑功能设置”** → 取消勾选 **“拒绝未映射的文件扩展名”**（不推荐，降低安全性）。

***

#### 方法三：临时重命名文件（最安全的临时方案）

将 `.bak` 文件临时改为 `.zip` 或 `.bin`：

```bash
rename data.bak data.zip
```

然后通过浏览器下载，下载后再改回 `.bak`。

***

### 🛡️ 安全建议（重要！）

* **永远不要在公网站点开放 **`.bak`**、**`.sql`**、**`.config`\*\* 等备份文件的访问权限\*\*；
* 如果必须传输备份文件，请使用 **SFTP、SCP、内网共享或加密压缩包**；
* 定期检查 IIS 日志，监控是否有对 `.bak`、`.old`、`.sql` 等敏感扩展名的扫描请求。
