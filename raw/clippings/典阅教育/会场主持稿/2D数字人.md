# 2D数字人

#

## 项目概述

本项目是一个数字人交互前端应用，包含HTML、CSS、JavaScript文件以及多媒体资源。支持语音交互、视频播放等功能。

## 系统要求

### 服务器配置

* **操作系统**: Windows Server 2016 或更高版本
* **内存**: 建议4GB以上
* **存储**: 至少10GB可用空间
* **网络**: 稳定的互联网连接

### 软件要求

* IIS 10.0 或更高版本
* .NET Framework 4.6 或更高版本
* URL Rewrite Module 2.1（可选，用于URL重写）

## 部署步骤

### 1. 启用IIS功能

#### 通过服务器管理器启用IIS

1. 打开**服务器管理器**
2. 点击**添加角色和功能**
3. 选择**基于角色或基于功能的安装**
4. 选择目标服务器
5. 在**服务器角色**中选择**Web服务器(IIS)**
6. 在**功能**页面，确保选择以下组件：
   * Web服务器
   * 常见HTTP功能
     * 默认文档
     * 目录浏览
     * HTTP错误
     * HTTP重定向
     * 静态内容
   * 性能
     * 静态内容压缩
     * 动态内容压缩
   * 安全性
     * 请求筛选
   * 应用程序开发
     * .NET Framework 4.6
     * ASP.NET 4.6
     * ISAPI扩展
     * ISAPI筛选器
   * 管理工具
     * IIS管理控制台
     * IIS管理脚本和工具

#### 通过PowerShell启用IIS（替代方法）

```powershell
# 以管理员身份运行PowerShell
Enable-WindowsOptionalFeature -Online -FeatureName IIS-WebServerRole, IIS-WebServer, IIS-CommonHttpFeatures, IIS-HttpErrors, IIS-HttpRedirect, IIS-ApplicationDevelopment, IIS-NetFxExtensibility45, IIS-HealthAndDiagnostics, IIS-HttpLogging, IIS-Security, IIS-RequestFiltering, IIS-Performance, IIS-WebServerManagementTools, IIS-ManagementConsole, IIS-IIS6ManagementCompatibility, IIS-Metabase, IIS-ASPNET45
```

### 2. 配置IIS站点

#### 创建站点目录

1. 在服务器上创建站点根目录，例如：`C:\inetpub\wwwroot\digital-human`
2. 确保IIS\_IUSRS用户组对该目录具有读取和执行权限

#### 创建IIS站点

1. 打开**IIS管理器**
2. 在左侧导航栏中右键点击**网站**
3. 选择**添加网站**
4. 配置以下信息：
   * **网站名称**: digital-human（或自定义名称）
   * **物理路径**: C:\inetpub\wwwroot\digital-human
   * **绑定类型**: HTTP
   * **端口**: 80（或自定义端口）
   * **主机名**: 可选，如 digitalhuman.yourdomain.com

### 4. IIS配置优化

#### 设置默认文档

1. 在IIS管理器中选择您的站点
2. 双击**默认文档**
3. 确保 `index.html` 在列表顶部，如果没有则添加

#### 配置MIME类型

确保以下MIME类型已配置（通常IIS已内置）：

* `.mp4` → `video/mp4`
* `.webm` → `video/webm`
* `.js` → `application/javascript`
* `.json` → `application/json`

#### 启用静态内容压缩

1. 选择站点，双击**压缩**
2. 启用**静态内容压缩**
3. 添加以下文件类型（如果尚未包含）：
   * `application/javascript`
   * `text/css`
   * `text/html`

#### 配置缓存策略

1. 选择站点，双击**HTTP响应头**
2. 点击**设置常用标头**
3. 启用**到期Web内容**，设置适当的缓存时间：
   * 图片和视频文件：7天
   * JavaScript和CSS文件：1天
   * HTML文件：1小时

### 5. 安全配置

#### 设置文件权限

确保以下权限设置：

* **IIS\_IUSRS**: 读取和执行
* **IUSR**: 读取
* **应用程序池标识**: 读取和执行

#### 配置请求筛选

1. 选择站点，双击**请求筛选**
2. 在**文件扩展名**选项卡中，确保允许以下扩展名：
   * `.html`
   * `.js`
   * `.css`
   * `.png`
   * `.jpg`
   * `.mp4`
   * `.webm`

#### 隐藏服务器信息

1. 双击**HTTP响应头**
2. 删除或修改**X-Powered-By**头
3. 在web.config中添加以下配置隐藏服务器版本：

```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <system.webServer>
    <httpProtocol>
      <customHeaders>
        <remove name="X-Powered-By" />
      </customHeaders>
    </httpProtocol>
    <security>
      <requestFiltering removeServerHeader="true" />
    </security>
  </system.webServer>
</configuration>

```

### 6. 性能优化

#### 应用程序池配置

1. 在IIS管理器中选择**应用程序池**
2. 右键点击站点对应的应用程序池，选择**高级设置**
3. 建议配置：
   * **回收条件** → **专用内存限制**: 500MB
   * **进程模型** → **闲置超时**: 00:00:00（禁用）
   * **CPU** → **限制**: 90000（90%）

#### 启用输出缓存（可选）

对于静态内容，可以启用输出缓存：

1. 选择站点，双击**输出缓存**
2. 点击**添加**，配置缓存规则
3. 为不同文件类型设置适当的缓存时间

### 7. SSL/TLS配置（推荐）

#### 申请SSL证书

1. 从可信CA申请SSL证书
2. 或使用Let's Encrypt免费证书

#### 配置HTTPS绑定

1. 在IIS管理器中右键点击站点
2. 选择**编辑绑定**
3. 点击**添加**，配置HTTPS绑定：
   * **类型**: https
   * **端口**: 443
   * **SSL证书**: 选择已安装的证书

#### 强制HTTPS重定向

在web.config中添加重定向规则：

```xml
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <system.webServer>
    <rewrite>
      <rules>
        <rule name="Redirect to HTTPS" stopProcessing="true">
          <match url=".*" />
          <conditions>
            <add input="{HTTPS}" pattern="off" ignoreCase="true" />
          </conditions>
          <action type="Redirect" url="https://{HTTP_HOST}/{R:0}"
                  redirectType="Permanent" />
        </rule>
      </rules>
    </rewrite>
  </system.webServer>
</configuration>

```

### 10. 维护和故障排除

#### 常见问题

1. **视频无法播放**
   * 检查MIME类型配置
   * 验证文件权限
   * 确认视频文件完整性
2. **JavaScript错误**
   * 检查浏览器控制台错误信息
   * 验证文件路径正确性
   * 确认所有依赖文件已上传
3. **性能问题**
   * 检查应用程序池回收策略
   * 验证缓存配置
   * 监控服务器资源使用情况

#### 维护任务

* 定期更新Windows系统补丁
* 监控磁盘空间使用情况
* 定期备份站点文件和配置
* 检查SSL证书有效期

### 11. 备份和恢复

#### 备份策略

1. **文件备份**: 定期备份站点文件
2. **配置备份**: 导出IIS配置
3. **数据库备份**: 如有数据库，制定备份计划

#### 备份命令示例

```powershell
# 备份站点文件
Copy-Item "C:\inetpub\wwwroot\digital-human" "D:\Backup\$(Get-Date -Format 'yyyyMMdd')-digital-human" -Recurse

# 导出IIS配置
Export-IISConfiguration -Path "D:\Backup\IIS-Config-$(Get-Date -Format 'yyyyMMdd').xml"
```
