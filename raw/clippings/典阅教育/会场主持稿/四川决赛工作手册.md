（**特别提示**：请决赛工作人员仔细阅读本《工作手册》，认真履职尽责，确保决赛圆满成功。另请决赛工作人员在工作期间着正装，并严格带头遵守会议纪律。）

一、赛事名称

四川农信第四届职工岗位技能（柜面业务）竞赛决赛。

二、时间安排

**（一）报到、预备会和彩排时间。**

2023年8月28日（星期一）16:00前，各代表队在四川农信学员公寓<font style="color:black;">报</font>到，全体人员务必携带身份证验证身份。

17:00在省联社G306阶梯教室召开领队及教练赛前预备会。

# 19：00-20：00参赛选手分批熟悉赛场；部分人员于20:00在省联社三楼多功能厅进行四川省农村信用社第四届职工岗位技能（柜面业务）竞赛决赛开（闭）幕式彩排。
**（二）决赛时间。**

2023年8月29日～30日。

三、比赛及食宿地点

决赛地点：省联社G310室

#     候赛地点：省联社G306阶梯教室、G303会议室
住宿地点：四川农信学员公寓

就餐地点：蓝海御华大饭店

四、参加人员

**    ****（一）开幕式。**

1.省联社分管领导；

2.省联社部（室、中心）负责人一名；

3.各市州参赛代表队。

**    ****（二）闭幕式。**

1.省总工会、人民银行四川省分行、国家金融监管总局四川监管局、四川省支付清算协会<u>、四川省银行</u><u>业协会</u>领导；

#     2.省联社领导；
3.省联社各部（室、中心）主要负责人；

4.各市州参赛代表队。

五、赛事组织及分工

**（一）领导小组**

为加强第四届职工岗位技能（柜面业务）竞赛决赛的组织领导，成立省联社第四届职工岗位技能竞赛决赛组委会。

组  长：谭红杰

副组长：郑立新

成  员：王力理、廖晓虹、王绍文、邓一戈

主要职责：研究、决定决赛重大事项；统筹、协调、督促决赛活动开展；组织决赛活动结果评选；协调决赛有关事宜。

**（二）领导小组办公室**

主  任：邓一戈

副主任：贺艳

成  员：邓丽、李小军、吴泽旺、曾云、文婷、付林永

主要职责：落实领导小组决定；负责决赛活动策划、组织、协调、联络、督办等工作；协调决赛活动赛事和费用审核；负决赛其他事项的协调和奖项审定工作等。

**（三）会务组**

组  长：邓一戈

#     副组长：贺艳
    成  员：邓丽、李小军、吴泽旺、曾云、文婷、魏骁、李洪舰、付林永、杨海平、赖毅洁

主要职责：负责决赛场地落实、布置，食宿安排；赛前报到；决赛期间车辆调度以及其它需落实的事项；礼仪人员、会场服务人员组织；负责决赛费用预决算。

1.负责决赛现场开、闭幕式LED背景图，工作人员、领队、教练、裁判及参赛选手挂牌设计，负责坐席包裹物料的设计，负责决赛会场标语横幅的内容；（**文婷**）

2.负责参会人员食宿安排（与蓝海御华酒店联系印制餐券）；**（文婷）**

3.负责安排布置开、闭幕式场地及座牌摆放；负责安排布置预备会、候考场地；制作现场座位表；**（邓丽、文婷）**

4.负责联系广告公司印制《赛事指南》、《工作手册》；参赛选手号牌；领导座牌、各地市州参赛人员座牌等的制作。负责联系广告公司完成竞赛厅背景墙、主持人讲台桌贴、话筒徽标、宣传牌、决赛会场横幅的制作布置；**（****文婷）**

# 5.负责拟写省总工会、人民银行、国家金融监管总局四川监管局邀请函。（杨海平）
# 6.负责邀请参加闭幕式的省总工会嘉宾；（邓丽）
7.负责邀请参加闭幕式的人民银行四川省分行、国家金融监管总局四川监管局、省银协、四川省支付清算协会嘉宾；（**贺艳**）

8.负责安排礼仪人员引领开、闭幕式领导、嘉宾入场（**邓丽**）

9.负责于8月28日，在鑫信合酒店大厅设置报到处，负责各市州参赛队伍的报到接待，分发《赛事指南》、参赛队员挂牌、餐券等；**（杨海平、魏骁）**

10.负责开、闭幕式，视频及颁奖仪式等音乐选曲及播放督促工作；**（杨海平）**

#     11.负责闭幕式上点钞展示人员的选拔、通知和组织。（李小军、吴泽旺）
# 12.负责统筹人员闭幕式上点钞展示的搭台和拆台。（邓丽、魏骁）
# 13.负责制作开幕式视频；（曾云）
#     14.负责闭幕式嘉宾用车对接；（魏骁）
# 15.负责开幕式省联社领导（谭红杰）讲话稿（曾云）；负责闭幕式省联社领导（郑立新）讲话稿（李小军）。
# 16.负责开幕式选手、裁判宣誓词和人选敲定及通知；（李小军、吴泽旺）
17.负责开、闭幕式环节主持词及主持；**（李洪舰、赖毅洁）**

18.负责决赛费用报销。**（付林永）**

**（四）比赛组**

组长：贺艳

组员：李小军、吴泽旺、曾婷婷、曾紫琳、舒妤、田永成、程万万、文婷、魏骁、刘琼、冯婷、黄兰、张鸿、罗嘉

主要职责：负责竞赛事项统筹；对竞赛争议事项进行裁定与解释；全程监督选手竞赛过程；竞赛抽签排序；收集选手、评委签字确认后的选手个人成绩表进行复核和统分。

1.负责清理决赛现场多余桌椅。**（李小军、物业）**

2.负责决赛场地考试系统环境搭建和调试；（**李小军、吴泽旺、罗嘉、张鸿**）

3.负责决赛现场规则公布；**（李小军、吴泽旺、罗嘉）**

4.负责对比赛现场进行监督，对可能出现的有争议的情况进行裁判仲裁；（**李小军、吴泽旺、罗嘉**）

5.负责抽签环节（赛前预备会）相关物料（抽签箱、号牌、抽签登记表）准备；（**文婷**）

6.负责抽签排序登记（赛前预备会）；**（****李小军、吴泽旺、曾婷婷、程万万、曾紫琳、刘琼、冯婷、黄兰****）**

# 7.负责竞赛物料准备（包括：点钞券，腰条，沾水盒，传票本、传票篮、印台、剪刀、签字笔、A4纸、笔记本等）。（文婷）
**   ** 8. 负责每场考试前的身份检录。**（程万万、魏骁）**

#    9.负责点钞机的借用保管和考试现场配券；（李小军、吴泽旺、曾婷婷、曾紫琳、舒妤、田永成、程万万、刘琼、冯婷、黄兰）
# 10.负责每场比赛的物件的清场收纳；（李小军、吴泽旺、曾婷婷、曾紫琳、刘琼、冯婷、黄兰）
11.负责安排现场成绩统计及上传工作；**（李小军、吴泽旺、罗嘉）**

12.负责比赛项目结束后及时将获奖名单交党群部登记，并将获奖名单传递给主持人；**（****李小军****）**

**（五）表彰组**

组长：邓一戈

成员：邓丽、文婷、魏骁、杨海平、付林永、李小军、吴泽旺

主要职责：开闭幕式指挥引导工作；表彰现场指挥、表彰礼仪服务和相关工作；其它需落实的事项。

1.根据竞赛名次及获奖情况制作闭幕式电子字幕；**（文婷）**

2.负责撰写比赛结果名次，制作在屏幕上显示名次的文档；（**李小军、吴泽旺**）

3.负责制作奖杯、奖牌、奖金牌并运送到闭幕式现场；（**文婷**）

# 4.负责安排获奖选手对应的颁奖领导及嘉宾；(文婷）
5.负责奖杯、奖牌、奖金牌现场管理；（**杨海平**）

6.负责通知获奖选手提前站位；（**魏骁**）

7.负责统筹礼仪人员对颁奖嘉宾引导和表彰时传送奖牌、奖杯和奖金牌；**（邓丽、礼仪人员）**

#     8.负责通知各比赛项目第一名选手准备获奖感言。（邓丽）
9.负责奖金发放。（**付林永**）

**（六）****宣传报道组**

组长：王力理

组员：张勇、文婷 

主要职责：负责内外宣传和决赛摄影摄像统筹。

1.负责决赛新闻通稿；**（文婷）**

2.负责决赛各场地摄影摄像统筹；**（张勇）**

3.负责决赛现场直播工作统筹；**（张勇）**

4.负责现场摄像、直播团队邀请。**（文婷）**

**（七）安全保卫组**

组长：常湘平

组员：周妍君

主要职责：负责制定决赛安全保卫工作实施细则；负责决赛期间的安全保卫工作等。

    1.负责落实决赛期间安全方案和安保综合应急处置预案；负责整个活动期间的安全保卫；负责组织安保人员实施安保工作；**（常湘平、周妍君）**

2.负责赛事期间竞赛秩序的维持；负责督促酒店排查住宿、会场、餐厅消防设施、消防通道、紧急通道、电器设备等安全隐患；负责预留紧急状态下人群疏散通道等；**（常湘平、周妍君）**

    3.负责决赛现场的安保工作。**（****常湘平、周妍君）**
