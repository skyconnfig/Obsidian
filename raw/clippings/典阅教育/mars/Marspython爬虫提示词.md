# Mars python爬虫提示词

### 多租户
```bash
你是一名资深Python全栈架构师，请帮我从0到1设计并生成一个企业级“多租户爬虫数据管理系统”（SaaS平台），要求支持租户隔离、高并发采集、数据分析（ECharts），代码可直接运行、结构清晰、符合生产环境规范。

========================
一、项目名称
======

XXX多租户爬虫数据平台（SaaS系统）

========================
二、核心目标（必须实现）
============

* 支持多租户（Tenant隔离）
* 每个租户数据完全隔离
* 每个租户独立爬虫任务
* 支持租户权限控制
* 支持数据可视化分析（ECharts）

========================
三、技术架构
======

【后端】

1. FastAPI（核心服务）

* 异步爬虫
* 数据API
* 高并发处理

2. Flask（管理后台）

* 用户管理
* 租户管理
* 权限控制
* 所有的文档需要在，对应的后端接口文档以md形式在docs文件夹，方便二次开发以及维护
3. 数据库

* MySQL（主库）
* SQLite3（开发环境）

4. 技术组件

* ORM：SQLAlchemy
* 缓存：Redis（推荐）
* 调度：APScheduler / Celery
* JWT认证

【前端】

* Vue 3 + Vite
* Pinia
* Axios
* ECharts（数据可视化）
* 开发环境以及正式环境局域网访问0.0.0.0
* 所有的文档需要在，对应的前端接口文档以md形式在docs文件夹，方便二次开发以及维护

========================
四、多租户设计（核心重点）
=============

必须实现三种租户隔离方案（至少实现一种，推荐第二种）：

方案1：字段隔离（简单）

* 每张表增加 tenant_id
* 查询必须带 tenant_id

方案2：逻辑隔离（推荐）

* 所有业务表包含 tenant_id
* 后端自动注入 tenant_id（中间件）
* 用户登录后绑定 tenant_id

方案3：数据库隔离（高级）

* 每个租户独立数据库（可选）

必须实现：

* 登录后自动识别 tenant_id
* 所有查询自动加 tenant_id
* 防止越权访问

========================
五、核心功能模块
========

1. 租户管理（超级管理员）

* 新建租户
* 删除租户
* 租户状态（启用/禁用）
* 租户套餐（限制任务数量）

2. 用户管理

* 用户登录（JWT）
* 用户绑定租户
* 用户CRUD
* 权限控制

3. 爬虫任务管理（按租户隔离）

* 创建任务
* 启动/停止
* 定时任务
* 状态监控

4. 数据采集（FastAPI）

* 异步并发爬虫
* 数据入库（带 tenant_id）

5. 数据管理

* 数据分页查询
* 条件筛选（按租户）

========================
六、数据可视化模块
=========

提供数据分析接口，供 ECharts 使用：

1. /api/dashboard/statistics

* 返回当前租户数据统计

2. /api/dashboard/trend

* 时间趋势（折线图）

3. /api/dashboard/category

* 分类占比（饼图）

要求：

* 每个租户只能看到自己的数据
* 支持多维度统计

========================
七、数据库设计（重点）
===========

必须输出SQL：

1. 租户表 tenant

* id
* name
* status
* create_time

2. 用户表 user

* id
* username
* password
* tenant_id
* role
* create_time

3. 爬虫任务 spider_task

* id
* tenant_id
* name
* url
* status
* cron
* create_time

4. 数据表 spider_data

* id
* tenant_id
* title
* content
* source
* create_time

5. 日志表 spider_log

* id
* tenant_id
* task_id
* status
* message
* create_time

========================
八、后端实现要求
========

必须实现：

1. 多租户中间件（核心）

* 自动获取 tenant_id（从JWT）
* 自动注入查询条件

2. 安全控制

* 禁止跨租户访问
* 所有接口必须校验 tenant_id

3. FastAPI模块

* 爬虫接口
* 数据接口

4. Flask模块

* 管理接口

========================
九、前端实现要求
========

必须实现：

1. 登录（带租户信息）
2. 租户切换（可选）
3. Dashboard页面（ECharts）

Dashboard必须包含：

* 当前租户统计数据
* 折线图
* 柱状图
* 饼图

========================
十、加分项（强烈建议）
===========

* 多租户缓存（Redis）
* 限流（防止滥用）
* WebSocket实时数据
* 数据导出Excel
* 大屏模式
* Docker部署

========================
十一、输出顺序
=======

1. 架构说明
2. 多租户设计说明（重点）
3. 数据库SQL
4. FastAPI代码
5. Flask代码
6. 前端代码（含ECharts）
7. 启动步骤
8. 接口测试说明

========================
十二、代码要求
=======

* 必须可运行
* 不允许伪代码
* 必须包含关键实现
* 注释清晰
* 符合企业级规范

```
