# **爬虫系统任务管理 — 前后端设计文档整理**

## **一、整体架构**

```plain
爬虫系统任务管理
├─ 前端(Vue 3 + Vite + Naive UI + Pinia + Vue Router + Axios)
│   ├─ 登录页
│   ├─ 主布局（左右结构）
│   ├─ 页面模块（任务管理 / 用户管理 / 数据可视化 / 系统设置）
│   └─ 图表（ECharts / AntV G2）
├─ 后端(Spring Boot 3 + MyBatis-Plus + MySQL 8 + Redis + Sa-Token)
│   ├─ 用户管理模块
│   ├─ 任务管理模块
│   ├─ 定时任务模块
│   └─ 状态监控模块
├─ 爬虫核心
│   ├─ spader.json（任务配置）
│   └─ spader.py（爬虫执行）
└─ 文档
    └─ docs（前端接口文档 + 后端接口文档 + 开发说明）
```

***

## **二、前端设计**

### **技术栈**

* Vue 3 + Vite
* Pinia（状态管理）
* Vue Router（history 模式）
* Axios（二次封装）
* Naive UI（UI 库）
* SCSS / CSS Modules（样式）
* 图标：ionicons5
* 图表：ECharts / AntV G2
* 支持响应式布局和移动端

### **UI设计规范**

* 布局：左右结构后台系统
  * 左侧菜单（支持折叠）
  * 右侧内容：Header + Tabs + 主体
* 登录页：左右布局（左展示 + 右登录）
* 主题颜色：

```plain
const themeOverrides = {

    primaryColor: '#111827',

```

### **核心模块**

1. **用户管理**
   * 登录 / 登出（Sa-Token）
   * CRUD（增删改查）
   * 状态控制（启用/禁用）
   * 分页查询
   * 权限控制（角色权限）
2. **任务管理**
   * 创建爬虫任务
   * 启动 / 停止任务
   * 定时任务配置（cron）
   * 任务列表 & 状态监控
   * 日志查看（任务执行日志）
3. **数据可视化**
   * 折线图 / 柱状图 / 饼图 / 仪表盘 / 大屏
   * 支持任务数据展示：成功率、执行次数、失败率、耗时统计
4. **系统设置**
   * 用户管理
   * 系统日志
   * 全局参数配置

### **路由结构示例**

```plain
/login
/dashboard
/users
/tasks
/tasks/:id/logs
/visualization
/settings
```

### **Axios 封装**

* 全局请求拦截器：添加 Token
* 全局响应拦截器：统一处理错误
* 支持分页、查询参数自动拼接
* 提供 `get`, `post`, `put`, `delete` 封装方法

## **三、后端设计**

### **技术栈**

* Spring Boot 3 (JDK 17+)
* MyBatis-Plus
* MySQL 8
* Redis（缓存，可选）
* Sa-Token（认证 + 权限）
* Knife4j（接口文档）
* Lombok + Jackson

### **数据库设计（简化）**

\*\*用户表 \*\*<code>**sys_user**</code>

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| id | bigint | 主键 |
| username | varchar | 用户名 |
| password | varchar | 密码（加密） |
| role\_id | bigint | 角色 |
| status | tinyint | 状态（启用/禁用） |
| create\_time | datetime | 创建时间 |

\*\*任务表 \*\*<code>**spider_task**</code>

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| id | bigint | 主键 |
| name | varchar | 任务名称 |
| config\_path | varchar | 配置文件路径（spader.json） |
| script\_path | varchar | 爬虫脚本路径（spader.py） |
| status | tinyint | 状态（待执行/执行中/停止/完成） |
| schedule | varchar | 定时任务 cron 表达式 |
| last\_run\_time | datetime | 上次执行时间 |
| next\_run\_time | datetime | 下次执行时间 |
| create\_time | datetime | 创建时间 |

\*\*日志表 \*\*<code>**spider_task_log**</code>

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| id | bigint | 主键 |
| task\_id | bigint | 任务ID |
| status | tinyint | 执行状态 |
| message | text | 日志内容 |
| start\_time | datetime | 开始时间 |
| end\_time | datetime | 结束时间 |

***

## **四、爬虫任务管理**

### **功能**

1. **创建任务**
   * 前端填写任务名、配置文件路径、脚本路径
   * 后端存储任务信息
2. **启动 / 停止任务**
   * 后端调用 Python 脚本执行
   * 状态更新至数据库
   * 支持异步执行 / 并发管理
3. **定时任务**
   * 使用 Spring 的 `@Scheduled` 或 Quartz
   * 支持 cron 表达式
4. **状态监控**
   * 前端实时轮询任务状态
   * 可视化任务执行情况（ECharts 折线图/柱状图/仪表盘）
5. **日志管理**
   * 支持分页查看任务执行日志
   * 可下载日志

***

## **五、数据可视化**

**功能点**

* 任务执行趋势（折线图）
* 各任务成功率统计（柱状图）
* 任务占比分析（饼图）
* 系统整体状态（仪表盘）
* 大屏模式：任务总数、运行中、失败、成功统计

**推荐图表组件**

* ECharts：
  * 折线图：任务执行趋势
  * 柱状图：任务执行次数
  * 饼图：任务占比
  * 仪表盘：成功率 / 停止率
  * 大屏：多图组合

## **六、文档管理**

  * 数据可视化接口说明

## **七、开发流程建议**

1. **后端**
   * 建表 + 实体类 + Mapper
   * Sa-Token 用户管理
   * 任务管理 CRUD + 启动/停止 + 定时任务
   * 日志管理 + 状态接口
   * Knife4j 接口文档生成
2. **前端**
   * 登录页 + 主布局
   * 用户管理模块
   * 任务管理模块（带状态监控和操作按钮）
   * 数据可视化模块
   * Axios 封装 + Pinia 状态管理
3. **爬虫调度**
   * Python 脚本调用 + 状态写入数据库
   * 定时任务触发
   * 日志收集
4. **可视化**
   * 前端轮询 / WebSocket 实时更新
   * ECharts 图表展示任务状态
5. **文档**
   * 前端接口文档
   * 后端接口文档
   * 数据库设计文档
