# 现场知识竞赛抢答系统

**详细开发文档（V1.0）**

## 一、项目概述

### 1. 项目目标

开发一套**低延迟、稳定、可部署于局域网**的现场知识竞赛系统，支持：

* 抢答 / 计分 / 倒计时
* 多终端协同（选手 APK、控制端、评委端、大屏端、软件设置端）
* 题库管理、随机抽题、实时答题
* 自动计分、排名展示
* 图片 / 音频 / 视频题目
* 适用于大型现场赛事、校园竞赛、单位活动

***

### 2. 系统角色划分（与图片完全对应）

| 角色 | 说明 |
| --- | --- |
| 大屏端 | 投影 / LED 屏展示 |
| 控制端 | 主持人操作 |
| 选手端 | 选手答题（APK / 平板） |
| 软件设置端 | 赛前配置 |
| 评委端（可选） | 人工判分 |

## 三、功能模块详细说明（逐一对应图片）

***

## 1️⃣ 大屏端

### 功能说明

* 显示当前题目
* 显示题型（单选 / 多选 / 判断 / 抢答）
* 显示倒计时
* 显示抢答结果
* 显示答案与解析
* 显示中场分数、总排名

### 页面模块

* 活动封面页
* 题目展示页
* 抢答动画页
* 答案公布页
* 排名展示页（个人 / 团队）

### 技术要点

* 全屏自适应（16:9 / LED）
* WebSocket 实时刷新
* 动画与音效同步

***

## 2️⃣ 控制端（主持人端）

### 功能说明

* 控制大屏显示内容
* 控制题目流程
* 控制抢答开始 / 停止
* 手动判分 / 修正分数

### 核心功能

* 下一题 / 上一题
* 开始答题
* 开始抢答
* 强制结束答题
* 公布答案
* 进入中场排名

### 安全

* 登录权限控制
* 操作日志记录

***

## 3️⃣ 选手端（APK）

### 功能说明

* 显示题目
* 抢答按钮
* 作答提交
* 实时反馈结果

### 功能细节

* 抢答模式：
  * 抢答按钮高亮
  * 先到先得（服务器判定）
* 答题模式：
  * 单选 / 多选 / 判断
  * 自动提交或倒计时提交
* 状态提示：
  * 抢答成功 / 失败
  * 正确 / 错误

### 技术要点

* WebSocket 长连接
* 本地防重复提交
* 心跳保活

***

## 4️⃣ 软件设置端

### 功能说明

* 系统初始化配置
* 比赛规则设置

### 配置项

* 比赛名称
* 队伍数量 / 人数
* 计分规则（加分 / 扣分）
* 抢答模式（加分 / 不扣分）
* 是否启用自动计分
* LOGO / 背景图

***

## 5️⃣ 题库管理

### 支持题型

* 单选题
* 多选题
* 判断题

***

## 1️⃣4️⃣ 抢答环节

### 流程

1. 控制端点击开始抢答
2. 服务端开启抢答锁
3. 首个到达即成功
4. 广播结果
5. 进入答题或直接判分

### 技术实现

* Redis `SETNX`
* 毫秒级时间戳判定
