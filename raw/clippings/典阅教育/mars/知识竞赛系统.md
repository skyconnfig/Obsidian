# 知识竞赛系统

### 1.
```plain
技术栈详情：
- 前端：Vue 3 + Vite + TypeScript（可选）
- UI库：Naive UI
- 路由：Vue Router (history模式)
- 状态管理：Pinia
- 图标：vicons/ionicons5
- 样式：CSS Modules/SCSS，主题色#18A058，统一变量
- 布局：后台标准左侧菜单+右侧内容，登录页左右布局
- 组件：自定义表格、表单、对话框、时间选择器、富文本、文件上传
- 表单验证：vee-validate或Naive UI提示
- 接口调用：axios，统一封装（token、错误处理、loading）
- 文件上传：直传接口或保存到服务器
```
