# 通用版提示词

```markdown
我要开发一套【在线考试系统】，技术栈如下：
- 后端：SpringBoot3.0.5 + MyBatis-Plus + MySQL + Redis + Sa-Token
- 管理后台：Vue3 + Vite + Naive UI + Pinia + Axios
- 小程序端：uni-app + uview-plus3.6.29

请为我生成一份完整的项目需求文档，包含：
1.  项目整体定位与核心功能说明
2.  后端模块设计、数据表结构与接口设计
3.  管理后台前端页面与交互需求
4.  小程序端前端页面与交互需求
5.  关键业务逻辑说明（组卷、考试流程、防作弊、判分）
6.  各端接口对接规则与数据流向说明

要求：
- 用 Markdown 格式，分模块清晰呈现
- 不写具体代码，只做需求与设计说明
- 适配前后端分离架构，明确各端职责与交互逻辑
## 一、整体样式
1. 页面布局合理、分区清晰、留白舒适，整体风格统一简约美观。
2. 统一配色、字体、圆角、阴影、间距，视觉层级分明。
3. 全局主题统一，按钮、卡片、弹窗样式标准化。

## 二、布局适配
1. 后台采用左侧菜单+顶部导航+内容区，菜单可折叠自适应。
2. 小程序底部Tab导航，全机型适配、兼容安全区，无错位溢出。
3. 电脑端多分辨率自适应，大屏不空旷、小屏不拥挤。

## 三、交互体验
1. 所有操作增加反馈，加载、请求、上传自带Loading/骨架屏。
2. 新增过渡动画，弹窗、切换、页面跳转流畅不生硬。
3. 按钮防重复点击，防止重复提交请求。
4. 删除、下架等高危操作，必须二次弹窗确认。
5. 成功/失败/警告统一Toast提示，文案简洁明了。

## 四、列表与数据页
1. 表格、列表美化排版，内容对齐整洁，状态标签可视化区分。
2. 支持多条件筛选、搜索、排序、分页，布局整洁。
3. 空数据、无搜索、网络异常，做友好空页面+重试按钮。
4. 长列表懒加载、上拉加载更多、下拉刷新。

## 五、表单与上传
1. 表单实时校验，错误提示精准展示，必填项明确标注。
2. 文件/图片/视频上传优化，支持预览、进度条、大小限制、失败重传。
3. 弹窗大小合理，表单排版规整，操作逻辑友好。

## 六、功能细节
1. 按角色做权限控制，无权限菜单、按钮自动隐藏或置灰。
2. 视频、文档、图片、音频预览体验优化，支持进度记忆。
3. 收藏、点赞、评论等互动操作，状态实时刷新更新。
4. 数据图表美化，展示清晰直观，样式简约高级。

---
## 优化所用技术
Flex/Grid 弹性栅格布局、响应式适配、统一设计规范、
过渡动画、骨架屏、节流防抖、防重点击、
全局状态管理、异常页面兜底、组件样式统一封装。

##表单优化
一、整体布局与结构
表格列宽自适应优化
隐藏无数据的「手机号」列，或设为可折叠列，避免空白占位。
「账号 / 昵称 / 角色 / 状态」列宽度固定，「创建时间 / 操作」列宽度自适应，确保内容不换行、不溢出。
操作列固定在表格最右侧，防止小屏下按钮被挤掉。
表格排版与对齐
所有单元格内容统一垂直居中，文本左对齐、数字 / 状态右对齐，排版整洁有序。
行与行之间增加浅灰色分隔线，hover 整行高亮背景，提升可读性。
二、视觉与色彩优化
角色标签优化
强化角色标签色彩对比度：
超管：深红色背景 + 白色文字，边框加深，增强警示感。
教师：深橙色背景 + 白色文字，区分普通用户。
用户：浅蓝色背景 + 白色文字，弱化展示。
标签文字统一加粗，hover 时显示完整角色说明 tooltip。
按钮样式统一与层级区分
「编辑」：统一为灰色边框按钮，hover 变深灰，和其他操作按钮形成层级差。
「重置密码」：统一为橙色主按钮，hover 加深橙色，增加明显的点击反馈。
「删除」：统一为红色危险按钮，hover 加深红色，仅在非超管用户行显示。
按钮间距固定为 8px，避免拥挤，hover 时显示对应操作的 tooltip 提示。
状态开关优化
开启状态：绿色开关 + 文字 “启用”。
禁用状态：灰色开关 + 文字 “禁用”。
开关点击时有平滑过渡动画，状态变化后显示成功 Toast 提示。
时间格式优化
将创建时间改为 YYYY-MM-DD HH:mm:ss 格式，可读性更强。
支持 hover 显示完整 ISO 时间戳，方便后台日志核对。
三、交互与权限逻辑优化
高危操作防护
「删除」按钮点击后，弹出二次确认弹窗，文案明确：“删除该用户后，其所有数据将无法恢复，确认删除？”
「重置密码」按钮点击后，弹出确认弹窗，文案提示：“重置后密码将恢复为初始密码，确认重置？”
所有高危操作按钮点击后禁用 2 秒，防止重复提交。
权限逻辑修复
超级管理员（admin）行隐藏「删除」按钮，仅保留「编辑」和「重置密码」（如需保留重置，需增加权限校验，仅指定账号可操作）。
无权限的用户（如普通教师），隐藏「删除」「重置密码」按钮，仅可见「编辑」按钮。
批量操作支持
表格首列增加复选框，支持批量选中用户，顶部显示批量删除 / 批量禁用按钮。
批量操作前弹出二次确认，显示选中用户数量，避免误操作。
状态反馈优化
所有按钮增加 loading 态，请求过程中显示加载图标，防止用户重复点击。
操作成功 / 失败后，显示对应颜色的 Toast 提示，文案简洁明确。
四、分页与附加功能优化
分页控件优化
分页控件增加「总条数」「当前页码 / 总页数」显示，支持手动输入页码跳转。
每页条数选项默认显示 10/20/50/100，支持自定义切换。
上一页 / 下一页按钮禁用态置灰，无法点击。
附加交互优化
表格顶部增加筛选 / 搜索栏，支持按账号 / 昵称 / 角色 / 状态搜索。
支持列排序：点击表头可按创建时间、账号、角色升降序排列。
无数据时显示友好空状态提示，文案为 “暂无用户数据”，搭配重试按钮。
```
