# 在线课程资源中心开发

```markdown
在线课程资源中心系统 — 完整开发需求文档
适用技术栈后端：SpringBoot3.0.5 + MyBatis-Plus + MySQL + Redis + Sa-Token管理后台：Vue3 + Vite + Naive UI + Pinia + Axios小程序端：uni-app + uview-plus3.6.29文档用途：需求说明、前后端分工、AI 生成代码依据格式：纯 Markdown、无代码、可直接复制使用
一、项目整体定位与核心功能
1.1 项目定位
一套前后端分离的在线课程资源中心系统，支持：
教师 / 管理员在后台上传、管理、发布课程资源
用户在微信小程序浏览、搜索、学习、收藏、评论资源
支持多类型资源：视频、音频、文档、图片、压缩包
支持权限控制：免费 / 积分 / 付费（可选扩展）
完整学习闭环：浏览 → 播放 / 查看 → 收藏 → 评论 → 学习记录
1.2 系统角色
超级管理员：系统配置、用户管理、资源审核、数据统计
教师：上传资源、管理自己发布的资源、查看学习数据
普通用户（小程序）：浏览、学习、收藏、评论、学习记录
1.3 核心功能
用户体系：登录、注册、个人信息、权限
资源分类：科目 / 分类 / 标签多级分类
资源管理：上传、编辑、下架、置顶、推荐
资源播放 / 预览：视频、文档、图片、音频
互动功能：收藏、点赞、评论、分享
学习中心：学习记录、继续学习、我的收藏
搜索功能：关键词搜索、分类筛选
积分 / 付费体系（可选）：下载 / 观看消耗积分
二、后端模块设计、数据表、接口设计
2.1 后端模块
用户与权限模块
资源分类模块
课程资源模块
收藏 / 点赞 / 评论模块
学习记录模块
搜索与推荐模块
文件上传与存储模块
系统配置与统计模块
2.2 核心数据表设计（关键字段）
用户表 sys_user
id、账号、昵称、头像、手机号、角色、密码、状态、创建时间
角色表 sys_role
id、角色名称、角色标识（admin/teacher/user）
资源分类表 category
id、父 ID、分类名称、排序、图标、状态
课程资源表 resource
id、标题、封面、简介、分类 ID、类型（视频 / 音频 / 文档 / 图片）、文件 URL、时长、大小、上传用户 ID、置顶、推荐、免费 / 积分 / 付费、积分数量、价格、浏览量、点赞量、收藏量、评论量、状态、创建时间
标签表 tag
id、标签名称、使用次数
资源标签关联表 resource_tag
resource_id、tag_id
学习记录表 study_record
id、用户 ID、资源 ID、进度（秒 / 页数）、学习时长、完成状态、更新时间
收藏表 collect
id、用户 ID、资源 ID、创建时间
点赞表 like_record
id、用户 ID、资源 ID、创建时间
评论表 comment
id、资源 ID、用户 ID、内容、回复 ID、状态、创建时间
文件表 file
id、文件名、文件 URL、大小、格式、上传人、上传时间
2.3 核心接口（RESTful）
2.3.1 认证接口
登录 / 注册 / 小程序微信授权登录 / 退出登录
获取用户信息 / 修改信息
2.3.2 分类接口
获取分类列表（树形）
获取分类下资源
2.3.3 资源接口
资源列表（分页、筛选、排序）
资源详情（浏览量 + 1）
上传资源 / 编辑 / 删除 / 上下架
推荐资源 / 最新资源 / 热门资源
2.3.4 学习记录
提交学习进度
获取学习记录 / 继续学习
清空学习记录
2.3.5 互动接口
收藏 / 取消收藏
点赞 / 取消点赞
发表评论 / 评论列表
删除评论（管理员 / 本人）
2.3.6 搜索接口
关键词搜索
按分类 / 类型 / 时间筛选
三、管理后台前端需求（Vue3 + Naive UI）
3.1 整体布局
左侧菜单 + 顶部用户信息 + 内容区
权限控制：不同角色看到不同菜单
3.2 核心页面
3.2.1 登录页
账号密码登录、验证码、记住密码
3.2.2 控制台 / 首页
资源总数、今日上传、学习人次、用户总数
图表：近 7 日上传 / 学习统计
3.2.3 用户管理
用户列表、新增 / 编辑 / 禁用、角色分配、重置密码
3.2.4 分类管理
树形分类、增删改查、排序、图标配置
3.2.5 资源管理（核心）
资源列表：搜索、筛选、状态、置顶、推荐
上传资源：标题、简介、分类、标签、封面、类型选择、文件上传、权限设置
编辑、下架、删除、查看数据
3.2.6 评论管理
评论列表、查看、删除、屏蔽
3.2.7 学习记录管理
按用户 / 按资源查看学习情况
3.2.8 系统设置
角色权限、菜单管理、上传配置、积分规则配置
3.3 通用交互
表格：分页、筛选、搜索、导出
表单：上传、校验、提交
弹窗：确认删除、预览
全局：Loading、Toast、错误提示
四、小程序端前端需求（uni-app + uview-plus）
4.1 全局架构
底部 Tab 3 个：首页 → 分类 → 我的
4.2 页面设计
4.2.1 登录页
微信授权一键登录
未登录无法进入播放、收藏、评论
4.2.2 首页（Tab1）
轮播图（推荐资源）
金刚区：视频、文档、音频、图片
推荐资源、最新资源、热门资源
搜索框（支持跳搜索页）
4.2.3 分类页（Tab2）
左侧一级分类
右侧二级分类 + 资源封面列表
点击分类 → 显示对应资源
4.2.4 搜索页
关键词搜索、历史记录、按类型筛选
4.2.5 资源详情页（核心）
封面、标题、简介、分类、标签、浏览 / 点赞 / 收藏
播放 / 预览区：视频播放、文档预览、音频播放
按钮区：收藏、点赞、分享、下载
学习进度自动保存
评论列表 + 发表评论
4.2.6 我的页面（Tab3）
头像、昵称
我的收藏
学习记录（继续学习）
我的评论
设置（关于、退出登录）
4.3 通用交互规范
页面懒加载、下拉刷新、上拉加载
视频自动记录播放进度
图片预览、文档预览、全屏播放
收藏 / 点赞 / 评论实时反馈
统一 Toast / 加载 / 错误提示
五、关键业务逻辑说明
5.1 资源上传与发布
教师 / 管理员上传 → 填写信息 → 提交发布
支持开启审核模式（可选）
下架后用户不可见
5.2 资源权限逻辑
免费：直接观看
积分：观看 / 下载消耗积分
付费：支付后观看（可扩展）
5.3 学习记录逻辑
进入详情自动生成记录
视频每 10 秒提交一次进度
支持 “继续学习”
记录保留 7/30 天（可配置）
5.4 收藏 / 点赞 / 防重复
同一用户只能收藏 / 点赞一次
取消则删除记录
5.5 搜索与推荐
标题 / 简介分词搜索
按浏览 / 收藏 / 时间排序
六、各端接口对接规则
6.1 统一响应格式
json
{ "code":200, "message":"ok", "data":{} }
6.2 状态码
200 成功
401 未登录
403 无权限
400 参数错误
500 服务异常
6.3 请求规则
管理后台：Authorization: Bearer {token}
小程序：token 放入请求头
所有写接口需登录校验
文件上传统一接口 /upload
6.4 数据流向
后台上传资源 → MySQL 保存 → 小程序读取 → 用户学习 → 进度提交 Redis/MySQL → 学习记录展示
6.5 接口文档
集成 Knife4j 自动生成在线接口文档

7.1 布局规范

登录页：左右布局（左侧展示 + 右侧登录）
```
