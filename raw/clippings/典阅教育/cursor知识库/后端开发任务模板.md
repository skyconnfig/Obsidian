## 注意事项

### 技术选型原则
1. 优先使用Spring Boot生态成熟的组件
2. 数据库操作统一使用MyBatis-Plus
3. 日志统一使用SLF4J + Logback
4. 测试框架使用JUnit 5 + Mockito
5. 保持架构简洁，专注核心功能演示

### 代码质量标准
1. 代码覆盖率：单元测试80%+，集成测试100%接口覆盖
2. 代码规范：遵循Google Java Style Guide
3. 文档完整：关键类和方法必须有JavaDoc注释
4. 性能要求：API响应时间<200ms（95%分位）
5. 安全要求：通过OWASP Top 10安全检查

### 项目管理
1. 每个TASK完成后需要Code Review
2. 关键节点需要进行系统集成测试
3. 生产环境发布前必须完成全面测试
4. 问题跟踪使用JIRA或类似工具
5. 代码版本管理使用Git Flow工作流
