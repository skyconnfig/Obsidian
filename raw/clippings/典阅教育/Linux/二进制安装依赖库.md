# 二进制安装依赖库

# [linux安装glibc2.14](https://www.cnblogs.com/jaww/p/12247066.html)
<font style="color:rgb(17, 17, 17);">下载glibc-2.14.1.tar.gz</font>

<font style="color:rgb(17, 17, 17);">解压：tar xzf glibc-2.14.1.tar.gz</font>

```sql
cd glibc-2.14.1
mkdir build
cd build
```

<font style="color:rgb(17, 17, 17);">安装</font>

<font style="color:rgb(17, 17, 17);">在build文件夹下操作：</font>

```shell
../configure --prefix=/usr/local/glibc-2.14.1 --with-headers=/usr/include
make j4

make install
```

<font style="color:rgb(17, 17, 17);">替换原有的libc.so.6软连接：</font>

```shell
cd lib64
rm -rf libc.so.6
```

<font style="color:rgb(17, 17, 17);">此时系统命令就不能使用了，我们执行下面命令，临时修改环境变量：</font>

```shell
export LD_LIBRARY_PATH=/usr/local/glibc-2.14.1/lib:$LD_LIBRARY_PATH 
```

<font style="color:rgb(0, 0, 0);background-color:rgb(245, 245, 245);"></font>

<font style="color:rgb(17, 17, 17);">创建软连接：</font><font style="color:rgb(0, 0, 0);background-color:rgb(245, 245, 245);">  
</font>

```shell
ln -s  /usr/local/glibc-2.14.1/lib/libc-2.14.1.so  /lib64/libc.so.6
```
