# 1Panel面板安装

1Panel（1计划面板）是一款开源的服务器运维管理面板，支持Linux系统，安装步骤如下：

### 安装命令（适用于主流Linux发行版）

通过官方提供的一键安装脚本进行安装，在服务器终端执行以下命令：

```bash
curl -sSL https://resource.fit2cloud.com/1panel/package/quick_start.sh -o quick_start.sh && sh quick_start.sh
```

### 安装过程说明

1. 执行命令后，脚本会自动检测系统环境（支持CentOS、Ubuntu、Debian等）
2. 按照提示选择安装路径（默认 `/opt/1panel`）
3. 等待安装完成，过程中会自动配置相关依赖

### 安装完成后

安装成功后，终端会显示面板访问地址、用户名和密码，类似如下信息：

```plain
1Panel 安装成功!
==================================================================
外网地址: http://xxx.xxx.xxx.xxx:端口号
内网地址: http://xxx.xxx.xxx.xxx:端口号
用户名: admin
密码: 随机生成的密码
==================================================================
```

### 注意事项

1. 确保服务器已开放面板所使用的端口（默认8888，可在安装过程中自定义）
2. 若忘记密码，可通过以下命令重置：

```bash
1panel reset-password
```

3. 安装前建议更新系统包并确保网络通畅

安装完成后，通过浏览器访问显示的地址，使用提供的账号密码登录即可开始使用1Panel面板管理服务器。
