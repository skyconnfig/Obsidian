## 一、Docker 容器化 (20篇)

### 安装与配置
```bash
# CentOS 安装 Docker（阿里云镜像源）
sudo yum install -y yum-utils
sudo yum-config-manager --add-repo http://mirrors.aliyun.com/docker-ce/linux/centos/docker-ce.repo
sudo yum install -y docker-ce docker-ce-cli containerd.io
systemctl enable docker --now

# 配置加速 + 生产环境配置（cgroup systemd + overlay2 + 日志限制）
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://82m9ar63.mirror.aliyuncs.com"],
  "exec-opts": ["native.cgroupdriver=systemd"],
  "log-driver": "json-file",
  "log-opts": { "max-size": "100m" },
  "storage-driver": "overlay2"
}
EOF
```

### 核心操作速查
| 操作 | 命令 |
|------|------|
| 拉取镜像 | `docker pull nginx:1.20.1` |
| 启动容器 | `docker run -d --restart=always -p 88:80 --name mynginx nginx` |
| 进入容器 | `docker exec -it 容器id /bin/bash` |
| 挂载卷 | `-v /data/html:/usr/share/nginx/html:ro` |
| 复制文件 | `docker cp 容器id:/path /host/path` |
| 保存镜像 | `docker save imageID -o name.tar` |
| 加载镜像 | `docker load -i name.tar` |
| 提交修改 | `docker commit -a "author" -m "msg" 容器id 新镜像:tag` |
| 清理空间 | `docker system prune -a` |
| 大小查看 | `docker system df -v` |

## 五、实战经验总结

### 故障排查
1. **Docker 拉取镜像失败**: 配置阿里云镜像加速器
2. **服务器 yum 源不可用**: 修改 `/etc/resolv.conf`（国内 114.114.114.114 / 国外 8.8.8.8）
3. **CentOS 7 网络配置**: 网卡重启 `service network restart`
4. **ADB 设备未识别**: 检查 USB 是否被虚拟机接管

### 最佳实践
1. Docker 生产配置：cgroup driver = systemd + 日志 100m 上限
2. 镜像迁移：`docker save` → 内网传输 → `docker load`
3. K8s 安装：指定版本 `docker-ce-20.10.7` 以避免兼容问题
4. CI/CD 多语言支持：统一 Jenkins pipeline 模板
