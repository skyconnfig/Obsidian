## 技术架构
- **后端**: .NET Core, Spring Boot, PHP, Java
- **前端**: Vue, React (Cloudecode)
- **数据库**: SQL Server, MySQL
- **部署**: Docker, IIS (+10万并发配置)
- **云服务**: 腾讯云、阿里云、内网服务器
